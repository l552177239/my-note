15.AgentSkills

lious 2026-09-15 AIAI应用开发技术 Skill能力封装流程固化

# 15. Agent Skills

系列第 15 篇。14 篇解决了"工具怎么接"——MCP 让工具可以跨进程、跨语言。但工具仍然是原子操作：查订单、取消订单、发短信。真实业务里的任务往往是一整套固定流程："处理退货"= 查订单 → 判断状态 → 取消 → 通知用户。 如果让 LLM 每步临场决策，每次结果都不一样。这一篇引入 Skill（技能）：把固定流程打包成一个可复用的能力单元，LLM 只负责触发，内部步骤写死。

# 14. MCP 协议

系列第 14 篇。13 篇的 Agent 工具都写在 Python 代码里——加个工具就要改代码、重启服务、重跑测试。这一篇引入 MCP（Model Context Protocol）：工具变成独立进程，通过标准协议暴露，Agent 动态发现、动态调用。Java 团队写工具服务，Python Agent 一行不改就能用。

# 12. Function Calling 与工具使用

# 11. 记忆与多轮对话

系列第 11 篇。前面的聊天都是"一问一答"——用户说"我想退货"，模型答完，用户追问"那运费谁出"，模型已经不记得刚才说的是退货了。这一篇解决"对话连续性"：怎么存历史、怎么在上下文窗口里管理历史、历史太长怎么办。 这是第 13 篇 Agent 的前置——Agent 做工具调用时天然需要记住之前调过什么。
