Redis五大基本数据类型

# Redis 五大基本数据类型

Redis 所有数据都是 Key 唯一，Value 分为 5 种基础类型，覆盖约 90% 业务场景。

# 0. 总览

类型 特性摘要 命令格式 典型场景
String 字符串 / 数字 / 二进制，最大 512MB SET key value / GET key 缓存、计数、限流、锁
Hash field-value 对象结构 HSET key field value / HGET key field 用户详情、商品信息
List 有序可重复，双向链表 LPUSH/RPUSH key value / LPOP/RPOP key 消息队列、时间线
Set 无序不可重复，集合运算 SADD key member / SMEMBERS key 去重、共同关注
ZSet 不可重复 + score 排序 ZADD key score member / ZRANGE key start stop 排行榜、权重排序

# 1. String 字符串（最常用）

# 1.1 特性

  • 最大 512MB
  • 可存字符串、数字、二进制
  • 支持自增 / 自减，适合计数器

# 1.2 场景

用户信息 JSON、配置项、计数器、限流、分布式锁

# 1.3 常用命令

SET key value                  # 设置键值
SETNX key value                # 仅当 key 不存在时进行 set
SETEX key seconds value        # set 键值对并设置过期时间（秒）
GET key                        # 获取值
INCR key                       # 自增 1（值须为整数）
DECR key                       # 自减 1
MSET k1 v1 k2 v2               # 批量设置
MGET k1 k2                     # 批量获取
EXPIRE key seconds             # 设置过期时间（秒）

# 2. Hash 哈希

# 2.1 特性

key → (field → value) 结构，适合对象字段存储，避免把整个对象拆成多个 String Key。

# 2.2 场景

用户详情、商品信息、订单临时数据

# 2.3 常用命令

HSET key field value       # 设置单个字段
HGET key field             # 获取单个字段
HGETALL key                # 获取全部 field-value
HMSET key f1 v1 f2 v2      # 批量设置字段（已废弃，可用 HSET 多字段）
HKEYS key                  # 获取所有 field
HVALS key                  # 获取所有 value

HSET user:1001 name "Alice" age 20  # 写入用户对象多字段
HGET user:1001 name                 # 读单个字段 → "Alice"
HGETALL user:1001                   # 读全部字段

# 3. List 列表

# 3.1 特性

  • 有序、可重复
  • 底层可看作双向链表，头尾操作极快
  • 适合队列、栈、时间线

# 3.2 场景

消息队列、动态列表、最新 N 条记录

# 3.3 常用命令

LPUSH key value            # 从左侧（头）插入
RPUSH key value            # 从右侧（尾）插入
LPOP key                   # 从左侧弹出
RPOP key                   # 从右侧弹出
LRANGE key start stop      # 按区间取值（0 -1 表示全部）

示例：

LPUSH mq:order order1      # 左侧入队 → [order1]
RPUSH mq:order order2      # 右侧入队 → [order1, order2]
LRANGE mq:order 0 -1       # 查看全部元素
LPOP mq:order              # 左侧出队 → order1

# 4. Set 集合

# 4.1 特性

  • 无序、不可重复
  • 支持交集 / 并集 / 差集

# 4.2 场景

去重、好友共同关注、抽奖池、权限集合

# 4.3 常用命令

SADD key member            # 添加成员（自动去重）
SMEMBERS key               # 返回全部成员
SISMEMBER key member       # 判断是否存在（1/0）
SINTER key1 key2           # 交集
SUNION key1 key2           # 并集

SADD tag:java redis spring           # java 标签集合
SADD tag:cache redis memcached       # cache 标签集合
SINTER tag:java tag:cache            # 交集 → redis

# 5. ZSet 有序集合

# 5.1 特性

  • 元素不可重复
  • 每个元素带 score，按分数排序
  • 适合排行榜、延时队列、权重排序

# 5.2 场景

游戏积分榜、热搜排行、按权重取 TopN

# 5.3 常用命令

ZADD key score member                      # 添加/更新成员及分数
ZRANGE key start stop [WITHSCORES]         # 按分数升序取区间
ZREVRANGE key start stop [WITHSCORES]      # 按分数降序取区间
ZSCORE key member                          # 查询成员分数
ZRANK key member                           # 查询升序排名（从 0 起）
1
2
3
4
5

示例：

ZADD rank:game 100 alice 95 bob 120 cindy  # 写入三人积分
ZREVRANGE rank:game 0 2 WITHSCORES         # 降序 Top3（含分数）
ZSCORE rank:game alice                     # alice 的分数 → 100

# 6. 选型速查

需求 优先类型
简单 KV / 计数 / 锁 String
对象多字段局部更新 Hash
队列、最新列表 List
去重、集合运算 Set
排行榜、按分排序 ZSet
