Java 介绍与学习路线

# Java 介绍与学习路线

适用人群：熟练 JavaScript、Python，掌握变量、函数、对象、异步、REST、JSON；有动态语言开发经验，目标掌握 Java 后端开发

# TL;DR（先看结论）

一句话路线：快速过 Java 语法 → 工程化（Maven / 测试 / Lombok / 日志）→ 先懂 Spring（IoC/DI/AOP）再写 SpringBoot REST → 回头补集合 / 泛型 / Stream → 攻克并发与 JVM → 完整项目收尾部署。

  • 通用编程语法快速扫读，重点学 Java 独有机制：静态类型、OOP、受检异常、值传递
  • 持续横向对比 JS / Python，同一个概念同步对照，重点抓差异点
  • Spring 先于 SpringBoot：先建立 IoC / DI / Bean / AOP 心智模型，再上手自动配置与 REST
  • 优先 Web 实战：先跑通 REST 接口，再回头补集合、IO、并发、JVM
  • 四大高频坑：① JS 单线程事件循环 ≠ Java 多线程；② 受检异常编译期强制；③ Java 只有值传递；④ 泛型存在类型擦除

# 🗺️ 路线总览（先看图）

# 相对「纯语法 → 再框架」路线的调整说明

本系列按 JS + Python 双动态语言背景 做了针对性调整（对照常见 Java 入门书）：

调整点 常见路线 本系列做法 原因
对比对象 多只对 C# / 无对比 全程对照 JS + Python 避免原型继承、动态类型、事件循环思维硬套
工程化时机 语法全学完再 Maven 阶段 2 立刻 Maven / JUnit / Lombok 脱离 javac，贴近真实项目
Spring 位置 直接 SpringBoot，或把 IoC 放到进阶 08 Spring → 09 SpringBoot Boot 是约定脚手架，不懂容器就只会「注解魔法」
Web 时机 集合 / IO / 并发后再写接口 阶段 3 先跑通 REST 最大化复用已有 Web 经验
集合 / 并发 基础阶段硬啃 Web 跑通后阶段 4→5 回头补 先能产出，再深挖

仍须盯住的差异坑：Node 事件循环 ≠ Java 多线程；受检异常；值传递；泛型擦除；JSON 强类型绑定。

# 核心学习原则

  1. 通用编程语法快速扫读：分支、循环、函数定义只看 Java 写法差异，不重复刷题
  2. 持续横向对比：同一个概念，同步对照 Python、JavaScript 的实现方式，重点抓差异点
  3. 先 Spring 再 Boot：用 Spring 笔记把 IoC / DI / AOP 讲透，再用 SpringBoot 写 REST
  4. 先能用，再深挖底层：跑通接口、数据库 CRUD 之后，回头补集合、IO、并发、JVM
  5. 警惕思维迁移坑：不要把 JS 原型、事件异步、Python 动态类型思维直接套用到 Java

# 推荐学习顺序

💡 一句话结论：阶段 1→2 打基础，阶段 3 先 Spring 后 SpringBoot 快速产出，阶段 4→5 回头补底层，阶段 6 收尾成完整项目。

# 阶段 1：Java 基础（快速通关，重点：静态类型、OOP、异常）

目标：建立 Java 语言模型，分清 Java VS Python VS JS 的核心差异

  1. Java 介绍：JDK/JVM、字节码、跨平台、JDK 发行版、生态
    • 建议选择 JDK 17 或 21（LTS），Spring Boot 3.x 要求 JDK 17+
  2. Java 基础语法
    • 基本数据类型 & 包装类（重点：Java 特有的 primitive 与包装类二分，如 int/Integer；JS 原始值在需要时自动装箱为对象，Python 一切皆对象）
    • 静态类型约束、类型转换，对比 Python 类型注解 / TypeScript
    • 方法、值传递（重中之重）：Java 只有值传递，基本类型传值，对象传引用的副本；JS/Python 常被误称为引用传递，实际是“按共享传递”（pass-by-sharing），需仔细区分
    • 方法重载
  1. Java 面向对象（核心章节，横向对比）
    • 类、对象、构造器；对比 JS 构造函数 / 类、Python 类
    • 访问修饰符 private protected public default：Java 有强制权限控制；JS/Python 只有约定（TypeScript 的访问修饰符仅编译期检查，运行时无效；Python 靠 _/__ 命名约定）
    • 继承、重写、super：Java 类只能单继承，对比 JS 原型继承、Python 多继承
    • 抽象类、接口：Java 接口，对比 Python ABC 抽象基类、JS interface（TS）；注意 Java 8+ 接口支持默认方法、静态方法，Java 9+ 支持私有方法
    • package 包管理、import、Jar 包
  1. Java 异常体系
    • 受检异常 vs 非受检异常（最大坑点！JS/Python 没有受检异常）
    • try-catch-finally、try-with-resources
    • 异常处理最佳实践：不要吞异常、使用自定义异常、全局异常处理器设计

✅ 阶段产出：编写多个类，练习继承与接口；理解静态类型带来的约束；分清三种语言 OOP 模型差异

# 阶段 2：工程化能力（前置学习，Java 必备）

目标：脱离手动 javac 编译，掌握现代 Java 项目开发方式

  1. Maven：项目目录结构、pom.xml、依赖管理、构建生命周期；多模块项目结构（对比 npm / pip）
  2. JUnit5 + Mockito：单元测试，对比 Python pytest、JS Jest；可补充 AssertJ、Testcontainers
  3. Lombok、日志框架 SLF4J + Logback（独立成篇，后续 Spring 构造器注入会大量用到 @RequiredArgsConstructor）
  4. 编程规范：阿里巴巴 Java 开发手册、Checkstyle、SpotBugs、SonarQube；IDEA 常用配置
  5. （可选）Gradle：在 Android 和部分后端项目中广泛使用

✅ 阶段产出：搭建 Maven 项目，引入第三方依赖，编写单元测试，掌握日志与样板代码消除

# 阶段 3：Spring 生态实战（先 Spring 后 Boot，核心阶段）

目标：先建立容器心智模型，再快速开发 REST 接口，对比 NestJS / FastAPI / Express

  1. 08 Spring 快速入门（先学）：IoC、DI、Bean 生命周期、AOP；对比 NestJS 容器级 DI、FastAPI Depends、Express 手动管理
  2. 09 SpringBoot 快速入门：自动配置、启动类、application.yml、内嵌 Tomcat、可执行 Jar；对比 Express / FastAPI
  3. 10 SpringBoot REST：参数绑定、DTO、@Valid、Jackson 强类型 JSON（已完成）
  4. 11 全局异常与 CORS：@RestControllerAdvice、统一错误体、跨域（已完成）
  5. 12 MyBatis + 13 MyBatis-Plus：半自动 SQL 映射与 CRUD 增强（已完成）
  6. 补充：SpringDoc OpenAPI（Swagger）；Spring Security 基础（认证、授权、JWT）
  7. 请求模型差异：Node.js 单线程事件循环 + 非阻塞 I/O；SpringBoot 默认 Tomcat 多线程 + 阻塞 I/O（09 已专节对比）

✅ 阶段产出：理解容器与自动配置；完整后端接口项目；分清 SpringBoot 与 Node.js 请求处理模型

# 阶段 4：Java 核心类库

目标：掌握开发高频工具类

  1. 14 集合框架（已完成）：List / Set / Map 选型，ArrayList / HashMap 直觉，equals/hashCode
  2. 泛型、注解（结合你 TS/Python 类型基础，重点理解泛型擦除；补充通配符 ? extends/? super、擦除带来的限制如不能 new T()、不能 instanceof T）；反射与注解处理
  3. 15 Java8+ Lambda、Stream 流（已完成）：对比 JS 箭头函数、数组高阶方法；惰性求值、只能消费一次、并行流边界
  4. 日期时间 API（java.time）
  5. IO / NIO
  6. Java 新特性：Optional、Record、Sealed Classes、模式匹配等

# 阶段 5：Java 进阶（难点，重点区分 JS 异步模型）

目标：理解 Java 并发模型，强制区分：JS 事件循环 与 Java 多线程
说明：IoC / AOP 已前置到阶段 3 的 Spring 笔记，本阶段不再重复入门，可按需深挖源码与扩展点

  1. 16 多线程与并发（已完成）：线程池、synchronized / volatile / Lock、juc 工具；强制对比 JS 事件循环
    • 深入可续：JMM 细节、锁优化、AQS、虚拟线程（Loom）
  2. 17 JVM 基础（已完成）：内存结构、GC、类加载、排查入门
  3. Spring 进阶（可选）：自动配置原理、条件装配、扩展点（阶段 3 已掌握 IoC/AOP 入门）
  4. Spring Cloud 微服务基础（可选）
  5. Netty（可选，高性能网络）
  6. 缓存与消息队列：Redis、RabbitMQ/Kafka（企业级常见组件）

# 阶段 6：项目实战 & 查漏补缺

  1. 18 实战项目：RESTful 后端系统（下一篇）：把 08～13 串成完整业务，含测试与打包
  2. 性能调优、常见坑点总结（结合 16 并发 + 17 JVM）
  3. Jar 包打包、部署运行
  4. 容器化与部署：Docker 打包、Kubernetes 基础

# 📌 学习小贴士（针对 JS+Python 开发者）

  1. 不要用 Node.js 的思维写 Java：Node 是单线程事件循环；Java 是多线程模型，并发编程思路完全不同
  2. JSON 序列化坑：JS/Python 会自动隐式转换数字、字符串；Java 强类型，类型不匹配直接报错
  3. 泛型：TS 泛型和 Java 泛型看起来相似，但 Java 存在泛型擦除，底层不一样，不要直接等同
  4. 异常：Python/JS 异常全部是非受检；Java 强制捕获或者声明受检异常，初期非常不习惯
  5. 写 Demo 优先做 Web 接口，不要长时间写控制台程序，Web 项目能最大化复用你已有经验
  6. Spring ≠ SpringBoot：先搞懂容器（08），再享受约定优于配置（09），避免只会「贴注解」
