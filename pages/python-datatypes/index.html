    # 1. 基础数据类型

    # 5. 各类型常用方法详解

    # 5.1 字符串 str

    字符串是不可变序列，所有修改操作都会返回新字符串。

    大小写转换

    方法 作用 示例 结果
    upper() 全大写 "hello".upper() "HELLO"
    lower() 全小写 "HELLO".lower() "hello"
    capitalize() 首字母大写 "hello world".capitalize() "Hello world"
    title() 每个单词首字母大写 "hello world".title() "Hello World"
    swapcase() 大小写互换 "Hello".swapcase() "hELLO"
    casefold() 强力小写（用于比较） "ß".casefold() "ss"

    查找与判断

    方法 作用 示例 结果
    find(sub) 查找子串位置（左→右） "hello".find("l") 2
    rfind(sub) 查找子串位置（右→左） "hello".rfind("l") 3
    index(sub) 同 find，找不到报错 "hello".index("x") ValueError
    count(sub) 统计子串出现次数 "hello".count("l") 2
    startswith(prefix) 是否以某前缀开头 "hello".startswith("he") True
    endswith(suffix) 是否以某后缀结尾 "hello".endswith("lo") True
    isdigit() 是否全为数字 "123".isdigit() True
    isalpha() 是否全为字母 "abc".isalpha() True
    isalnum() 是否全为字母或数字 "abc123".isalnum() True
    isspace() 是否全为空白 " ".isspace() True
    islower() / isupper() 是否全小写/大写 "abc".islower() True

    截取与替换

    方法 作用 示例 结果
    strip() 去除首尾空白 " hello ".strip() "hello"
    lstrip() 去除左侧空白 " hello".lstrip() "hello"
    rstrip() 去除右侧空白 "hello ".rstrip() "hello"
    strip(chars) 去除指定字符 "xxhelloxx".strip("x") "hello"
    replace(old, new) 替换子串 "hello".replace("l", "x") "hexxo"
    replace(old, new, count) 替换指定次数 "hello".replace("l", "x", 1) "hexlo"
    split(sep) 按分隔符拆分 "a,b,c".split(",") ["a","b","c"]
    split() 按空白拆分 "a b c".split() ["a","b","c"]
    rsplit(sep) 从右侧拆分 "a.b.c".rsplit(".", 1) ["a.b", "c"]
    splitlines() 按行拆分 "a\nb".splitlines() ["a","b"]
    join(iterable) 用字符串连接 "-".join(["a","b"]) "a-b"
    partition(sep) 拆成三部分 "a.b.c".partition(".") ("a", ".", "b.c")

    对齐与填充

    方法 作用 示例 结果
    center(width) 居中 "hi".center(6) " hi "
    ljust(width) 左对齐 "hi".ljust(6) "hi "
    rjust(width) 右对齐 "hi".rjust(6) " hi"
    zfill(width) 左侧补零 "42".zfill(5) "00042"

    字符串格式化

    name, age = "Alice", 20

# f-string（推荐）
f"我叫{name}，今年{age}岁"
f"圆周率: {3.14159:.2f}"      # 3.14
f"编号: {5:03d}"              # 005
f"百分比: {0.85:.1%}"         # 85.0%

# format() 方法
"我叫{}，今年{}岁".format(name, age)
"我叫{0}，{0}今年{1}岁".format(name, age)
"我叫{name}，今年{age}岁".format(name="Bob", age=25)

# 旧式 % 格式化
"我叫%s，今年%d岁" % (name, age)

    # 5.2 列表 list

    列表是可变序列，支持增删改查。

    增：添加元素

    方法 作用 示例 结果
    append(x) 末尾添加单个元素 lst.append(4) [1,2,3,4]
    extend(iter) 末尾添加多个元素 lst.extend([4,5]) [1,2,3,4,5]
    insert(i, x) 在索引 i 处插入 lst.insert(1, "a") [1,"a",2,3]
    + 运算符 拼接两个列表 [1,2] + [3,4] [1,2,3,4]
    * 运算符 重复列表 [1,2] * 2 [1,2,1,2]

    删：删除元素

    方法 作用 示例 结果 说明
    remove(x) 删除第一个值为 x 的元素 lst.remove(2) [1,3] 找不到报错
    pop(i) 删除并返回索引 i 的元素 lst.pop(1) 返回 2 默认删最后一个
    pop() 删除并返回最后一个 lst.pop() 返回 3
    del lst[i] 删除索引 i 的元素 del lst[1] [1,3] 语句，非方法
    del lst[i:j] 删除切片 del lst[1:3] 删除索引 1,2
    clear() 清空列表 lst.clear() []

    改：修改元素

    方法/操作 作用 示例 结果
    lst[i] = x 修改单个元素 lst[0] = 99 [99,2,3]
    lst[i:j] = [...] 修改切片 lst[1:3] = [8,9] [1,8,9]
    reverse() 原地反转 lst.reverse() [3,2,1]
    sort() 原地排序 lst.sort() 升序排列
    sort(reverse=True) 降序排序 lst.sort(reverse=True) 降序排列
    sort(key=func) 自定义排序 lst.sort(key=len) 按长度排序

    查：查找元素

    方法 作用 示例 结果
    index(x) 查找 x 的索引 lst.index(2) 1
    index(x, start, end) 在范围内查找 lst.index(2, 2, 5)
    count(x) 统计 x 出现次数 lst.count(2)
    in 运算符 判断是否包含 2 in lst True
    len(lst) 获取长度 len([1,2,3]) 3

    列表推导式

    # 基础
squares = [x**2 for x in range(5)]        # [0, 1, 4, 9, 16]

# 带条件
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# 多重循环
pairs = [(x, y) for x in [1,2] for y in ["a","b"]]

# 带 else
result = ["偶" if x % 2 == 0 else "奇" for x in range(5)]
# ["偶", "奇", "偶", "奇", "偶"]

    # 5.3 元组 tuple

    元组是不可变序列，创建后不能增删改元素，但元素如果是可变的（如列表），其内容可以修改。

    常用操作

    方法/操作 作用 示例 结果
    count(x) 统计 x 出现次数 (1,2,2,3).count(2) 2
    index(x) 查找 x 的索引 (1,2,3).index(2) 1
    len(t) 获取长度 len((1,2,3)) 3
    + 运算符 拼接 (1,2) + (3,4) (1,2,3,4)
    * 运算符 重复 (1,2) * 2 (1,2,1,2)
    in 运算符 判断是否包含 2 in (1,2,3) True

    元组解包

    # 基础解包
a, b, c = (1, 2, 3)

# 带 * 的解包
first, *rest = (1, 2, 3, 4)     # first=1, rest=[2,3,4]
*middle, last = (1, 2, 3, 4)    # middle=[1,2,3], last=4
first, *mid, last = (1,2,3,4)   # first=1, mid=[2,3], last=4

# 交换变量
a, b = b, a

# 函数多返回值
def min_max(nums):
    return min(nums), max(nums)
minimum, maximum = min_max([3,1,4])

    # 5.4 字典 dict

    字典是键值对集合，键必须是不可变类型（str、int、tuple 等），值可以是任意类型。

    增：添加/修改

    方法/操作 作用 示例 结果
    d[key] = value 添加或修改键值 d["age"] = 20
    update(dict) 批量更新 d.update({"a":1, "b":2})
    setdefault(k, v) 键不存在则设置 d.setdefault("x", 0) 返回现有值或新值

    删：删除元素

    方法 作用 示例 结果 说明
    del d[key] 删除键值对 del d["name"] 键不存在报错
    pop(key) 删除并返回值 d.pop("name") 返回对应的值 键不存在报错
    pop(key, default) 安全删除 d.pop("x", None) 返回 None 键不存在返回默认值
    popitem() 删除并返回最后项 d.popitem() ("key", value) Python 3.7+ 保持插入顺序
    clear() 清空字典 d.clear() {}

    查：查找元素

    方法/操作 作用 示例 结果 说明
    d[key] 按键取值 d["name"] 值 键不存在报错
    get(key) 安全取值 d.get("name") 值或 None 键不存在不报错
    get(key, default) 带默认值 d.get("x", 0) 0
    keys() 获取所有键 d.keys() 视图对象
    values() 获取所有值 d.values() 视图对象
    items() 获取所有键值对 d.items() 视图对象
    in 运算符 判断键是否存在 "name" in d True 判断的是键
    len(d) 获取键值对数量 len(d)

    字典推导式

    # 5.5 集合 set

    集合是无序、不重复的元素集合，支持数学集合运算。

    增：添加元素

    方法 作用 示例 说明

    方法 作用 示例 说明

    discard(x) 安全删除 s.discard(2) 不存在不报错

    issuperset(s) >= 是否为超集 a >= b

    # 6. 切片（Slicing）详解

    切片是 Python 中访问可迭代数据类型子序列的强大语法，适用于 字符串、列表、元组、字节序列 等有序序列。

    # 6.1 基础语法

    sequence[start:end:step]
# start: 起始索引（包含），默认 0
# end:   结束索引（不包含），默认 len
# step:  步长，默认 1
    1
    2
    3
    4

    # 6.2 字符串切片

    s = "Hello, World!"

s[0:5]      # "Hello"     索引 0~4
s[:5]       # "Hello"     省略 start，从开头
s[7:]       # "World!"    省略 end，到末尾
s[:]        # "Hello, World!"  复制整个字符串
s[::2]      # "Hlo ol!"   每隔一个取一个
s[::-1]     # "!dlroW ,olleH"  反转字符串
s[-1]       # "!"         最后一个字符
s[-6:-1]    # "World"     倒数第6到倒数第2
s[-6:]      # "World!"    倒数第6到末尾

    # 6.5 切片速查表

    语法 含义 示例 lst = [0,1,2,3,4,5]
    lst[:] 浅拷贝 [0,1,2,3,4,5]
    lst[start:end] 索引 start 到 end-1 lst[1:4] → [1,2,3]
    lst[start:] 从 start 到末尾 lst[3:] → [3,4,5]
    lst[:end] 从开头到 end-1 lst[:3] → [0,1,2]
    lst[::step] 每隔 step-1 个取一个 lst[::2] → [0,2,4]
    lst[::-1] 反转 [5,4,3,2,1,0]
    lst[-1] 最后一个元素 5
    lst[-3:] 最后3个 [3,4,5]
    lst[:-2] 除最后2个外全部 [0,1,2,3]
    lst[start:end:step] 组合使用 lst[1:5:2] → [1,3]

    # 7. 可变 vs 不可变（核心概念）

    可变（可修改） 不可变（不可修改）

    # 可变与不可变的深入理解

    # 不可变类型的 id 会改变
