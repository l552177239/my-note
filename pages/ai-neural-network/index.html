# 神经网络

从神经元与 MP 模型、前向/反向传播到欠拟合与过拟合，梳理神经网络的基本概念与常见架构。

# 1. 引言

神经网络（Neural Network）是机器学习中连接主义的核心模型，通过模拟生物神经元的结构和连接方式，实现对复杂函数的逼近与学习。现代深度学习均建立在神经网络基础之上，广泛应用于图像、语音、自然语言处理等领域。

# 2. 神经元与MP模型

# 2.1 神经元结构

神经元是神经网络的基本计算单元，具有多输入、单输出的特性。其数学描述通常采用 MP（McCulloch-Pitts）模型：

[ y = \sigma(w_1x_1 + w_2x_2 + \dots + w_nx_n + b) ]

  • 输入向量：([x_1, x_2, \dots, x_n])，每个 (x_i) 代表一维输入信息。
  • 权重 (w_1, w_2, \dots, w_n)：表示各输入维度的重要程度，是可学习参数。
  • 偏置 (b)：调整神经元激活的阈值，改变函数起始位置。
  • 激活函数 (\sigma(\cdot))：引入非线性，使网络能够拟合复杂函数。
  • 输出值 (y)（也称激活值）：一个标量，作为下一层神经元的输入。

# 2.2 激活函数

激活函数为神经网络引入非线性。常见的激活函数包括 Sigmoid、Tanh、ReLU 等。

  • ReLU（Rectified Linear Unit）： [ \text{ReLU}(z) = \max(0, z) ] 优点：计算简单、缓解梯度消失、加速收敛；缺点：存在神经元“死亡”问题。

# 3. 前向传播

前向传播（Forward Propagation）是指输入信号从输入层经过隐藏层，最终到达输出层的过程，用于计算预测值。

对于第 (l) 层的第 (j) 个神经元，其激活值为：

[ a_j^{(l)} = \sigma\left( \sum_{i} w_{ji}^{(l)} \cdot a_i^{(l-1)} + b_j^{(l)} \right) ]

  • (l)：层编号。
  • (j)：当前层第 (j) 个神经元。
  • (w_{ji}^{(l)})：连接第 (l-1) 层第 (i) 个神经元到第 (l) 层第 (j) 个神经元的权重。
  • (a_i^{(l-1)})：上一层第 (i) 个神经元的输出。

通过逐层计算，最终得到网络的输出预测值。

# 4. 损失函数

损失函数（Loss Function）用于衡量模型预测值与真实标签之间的差距，是优化目标的量化。

常用的**均方误差（MSE）**损失函数：

[ L = \frac{1}{m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 ]

  • (m)：样本数量。

  • (y_i)：第 (i) 个样本的真实标签。

  • (\hat{y}_i)：第 (i) 个样本的预测值。

  • 损失值越大：预测值与真实值差距越大，模型性能越差。

  • 损失值越小：预测越准确。

# 5. 梯度下降与学习速率

# 5.1 梯度下降

梯度下降（Gradient Descent）是一种优化算法，通过迭代更新参数使损失函数最小化。

  • 梯度方向：损失函数对参数的导数方向，指向损失上升最快的方向。
  • 更新规则：沿梯度的负方向移动，使损失函数逐步减小。

# 5.2 学习速率

学习速率（Learning Rate，(\eta)）控制每次参数更新的步长。

  • 过大：可能导致损失震荡甚至发散。
  • 过小：收敛速度慢，易陷入局部最优。

比喻：损失函数曲面如同山谷，梯度指示下山方向，学习率决定每一步迈出的大小。

# 6. 反向传播

反向传播（Backpropagation）是训练神经网络的核心算法，利用链式法则计算损失函数对每个参数的梯度，以便进行梯度下降更新。

# 6.1 流程

  1. 前向传播：输入数据，计算预测值，得到损失。
  2. 反向计算梯度：从输出层开始，逐层计算损失对各参数的偏导数。
  3. 参数更新：使用梯度下降公式更新所有权重和偏置。

# 6.2 链式法则

对于复合函数 (f(g(x)))，其导数为：

[ \frac{df}{dx} = \frac{df}{dg} \cdot \frac{dg}{dx} ]

反向传播正是利用这一法则，将误差从输出层逐层传递至输入层，从而高效计算所有参数的梯度。

# 7. 模型训练与泛化

# 7.1 训练过程概述

训练神经网络的基本步骤：

  1. 初始化网络参数。
  2. 前向传播，计算损失。
  3. 反向传播，计算梯度。
  4. 梯度下降更新参数。
  5. 重复 2-4 直至损失收敛或达到预设轮数。

# 7.2 拟合状态

  • 欠拟合（Underfitting）：模型过于简单，无法充分学习训练数据的特征，训练集和测试集表现均差。

    • 原因：模型容量不足、特征提取不够、训练不充分。
    • 解决：增加模型复杂度、增加特征、延长训练时间。

  • 过拟合（Overfitting）：模型在训练集上表现极好，但在测试集上表现差，泛化能力弱。

    • 原因：模型过于复杂、训练数据过少、训练时间过长，模型“死记硬背”训练数据。
    • 解决：增加数据量、正则化、Dropout、早停（Early Stopping）。

  • 泛化能力（Generalization）：模型对未见过的数据也能做出正确预测的能力，是评价模型优劣的关键指标。

# 8. 常见网络架构

# 8.1 卷积神经网络（CNN）

  • 特点：局部连接、权值共享、池化操作，擅长处理网格化数据（如图像）。
  • 典型应用：图像分类、目标检测、语义分割。

# 8.2 Transformer

  • 特点：基于自注意力机制（Self-Attention），并行处理序列数据，长距离依赖建模能力强。
  • 典型应用：自然语言处理（NLP）起家，现已扩展到计算机视觉、多模态大模型（如BERT、GPT系列）。

# 9. 深度学习框架

# 9.1 PyTorch

  • 定位：当前学术界和工业界主力训练框架。
  • 特点：动态计算图，易于调试；Pythonic 风格，上手快；社区生态丰富。

# 9.2 TensorFlow

  • 定位：常用于边缘部署和生产环境。
  • 特点：静态图（2.x 支持动态图），部署工具链完善（如 TensorFlow Lite、TensorFlow Serving）。

# 10. 模型保存与加载

训练完成后，模型通常以文件形式保存，包括网络结构和参数信息。

  • 常见格式：
    • *.pth：PyTorch 保存的权重文件。
    • *.h5：Keras/TensorFlow 保存的模型文件。
    • *.onnx：开放神经网络交换格式，便于跨框架部署。

保存内容一般包括：模型架构、各层权重、偏置等参数，以及优化器状态（可选）。
