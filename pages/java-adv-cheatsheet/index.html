# 附录：进阶速查表

# 1. 关键字与修饰符

关键字 含义
final 类不可继承 / 方法不可重写 / 变量不可再赋值
static 属于类，而非实例
abstract 抽象类 / 抽象方法
synchronized 互斥同步
volatile 可见性
transient 序列化时忽略字段
native JNI 本地方法
strictfp 严格浮点（少用）
sealed / permits 密封类（Java 17+）
record 不可变数据载体（Java 16+）
var 局部变量类型推断（Java 10+）

# 2. 面向对象对照

概念 Java 要点
封装 private + getter/setter
继承 单继承 extends
多态 父类引用 + 方法重写
接口 implements，可多实现
抽象类 可有状态与构造
重载 / 重写 参数列表不同 / 子类覆盖父类

# 3. 泛型常用写法

List<String> list = new ArrayList<>();
Map<String, List<Integer>> map = new HashMap<>();

public static <T> T first(List<T> list) {
    return list.isEmpty() ? null : list.get(0);
}

// 通配符
List<? extends Number> src;  // 生产者：可读
List<? super Integer> dst;   // 消费者：可写

# 6. 异常选择

场景 建议
编程错误（空指针、越界） 修代码；RuntimeException
业务可恢复错误 自定义非检查异常或返回 Result
库的强制处理 IO/SQL 检查异常或包装后抛出

# 7. 集合选型

需求 选择
有序列表 ArrayList
去重 HashSet
去重且保序 LinkedHashSet
排序集合 TreeSet
键值缓存 HashMap
并发 Map ConcurrentHashMap
队列 ArrayDeque / LinkedBlockingQueue

# 8. 学习路线（进阶）

  1. 集合 + 泛型 + 异常熟练
  2. IO / NIO、并发基础
  3. JDBC → MyBatis 或 JPA
  4. Maven + JUnit
  5. Spring Boot Web
  6. 阅读 廖雪峰 Java 教程 (opens new window) 反射、注解、设计模式等章节
  7. 对照 Dotcpp Java 教程 (opens new window) 补语法细节与习题
