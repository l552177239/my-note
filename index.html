15.AgentSkills

# 15. Agent Skills

系列第 15 篇。14 篇解决了"工具怎么接"——MCP 让工具可以跨进程、跨语言。但工具仍然是原子操作：查订单、取消订单、发短信。真实业务里的任务往往是一整套固定流程："处理退货"= 查订单 → 判断状态 → 取消 → 通知用户。 如果让 LLM 每步临场决策，每次结果都不一样。这一篇引入 Skill（技能）：把固定流程打包成一个可复用的能力单元，LLM 只负责触发，内部步骤写死。

# 14. MCP 协议
