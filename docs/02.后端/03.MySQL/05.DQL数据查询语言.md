# DQL 数据查询语言（核心）

DQL 以 `SELECT` 为核心，覆盖条件过滤、排序、聚合、分组、分页、连接与子查询。表名以 [经典示例数据](/pages/mysql-examples/) 为准，可直接动手练习。

<!-- more -->

## 0. 完整查询模板

书写顺序与逻辑执行顺序不同，详见 [SQL概述 - SELECT 逻辑执行顺序](/pages/mysql-basic/#5-select-逻辑执行顺序)。

```sql
SELECT   列 | 表达式 | 聚合函数   -- ⑤
FROM     表
JOIN     表 ON 连接条件           -- ①
WHERE    行级条件                 -- ② 分组前，不能用聚合
GROUP BY 分组列                   -- ③
HAVING   分组后条件               -- ④ 可用聚合
ORDER BY 排序列                   -- ⑥
LIMIT    偏移, 条数;              -- ⑦
```

## 1. 基础查询

```sql
-- 查询所有列（生产环境慎用 SELECT *）
SELECT * FROM employees;

-- 查询指定列
SELECT name, salary FROM employees;

-- 去重
SELECT DISTINCT dept_id FROM employees;

-- 别名
SELECT 
    name AS 姓名,
    salary * 12 AS 年薪
FROM employees;

-- 常量列
SELECT name, '正式员工' AS 员工类型 FROM employees;

-- CASE WHEN 条件表达式
SELECT 
    name,
    salary,
    CASE 
        WHEN salary >= 15000 THEN '高'
        WHEN salary >= 10000 THEN '中'
        ELSE '低'
    END AS 薪资等级
FROM employees;
```

## 2. WHERE 条件过滤

```sql
-- 比较运算符
SELECT * FROM employees WHERE salary > 10000;
SELECT * FROM employees WHERE age <> 25;        -- != 也可以
SELECT * FROM employees WHERE salary BETWEEN 5000 AND 10000;

-- 逻辑运算符（AND 优先级高于 OR，拿不准就加括号）
SELECT * FROM employees WHERE age > 25 AND salary > 8000;
SELECT * FROM employees WHERE dept_id = 1 OR dept_id = 2;
SELECT * FROM employees WHERE NOT gender = 'M';

-- IN / NOT IN
SELECT * FROM employees WHERE dept_id IN (1, 2, 3);
SELECT * FROM employees WHERE dept_id NOT IN (4, 5);

-- LIKE 模糊查询
SELECT * FROM employees WHERE name LIKE '张%';     -- 张开头
SELECT * FROM employees WHERE name LIKE '%三';     -- 三结尾
SELECT * FROM employees WHERE name LIKE '%伟%';    -- 包含伟
SELECT * FROM employees WHERE name LIKE '李_';     -- 李+任意一个字符

-- NULL 判断（不能用 = / !=）
SELECT * FROM employees WHERE manager_id IS NULL;
SELECT * FROM employees WHERE manager_id IS NOT NULL;
-- SELECT * FROM employees WHERE manager_id = NULL;  -- ❌ 永远得不到行
```

`IFNULL` / `COALESCE` 等空值处理见 [常用函数](/pages/mysql-functions/)。

## 3. 排序 ORDER BY

```sql
-- 升序（默认）
SELECT * FROM employees ORDER BY salary ASC;

-- 降序
SELECT * FROM employees ORDER BY salary DESC;

-- 多字段排序
SELECT * FROM employees 
ORDER BY dept_id ASC, salary DESC;

-- 按表达式排序
SELECT * FROM employees 
ORDER BY salary * 12 DESC;
```

## 4. 聚合函数

| 函数 | 说明 |
|------|------|
| `COUNT(*)` | 统计行数 |
| `COUNT(列名)` | 统计该列非 NULL 的行数 |
| `SUM(列名)` | 求和（忽略 NULL） |
| `AVG(列名)` | 平均值（忽略 NULL） |
| `MAX(列名)` | 最大值 |
| `MIN(列名)` | 最小值 |

```sql
SELECT 
    COUNT(*) AS 总人数,
    COUNT(manager_id) AS 有上级的人数,  -- manager_id 为 NULL 的不计入
    AVG(salary) AS 平均薪资,
    MAX(salary) AS 最高薪资,
    MIN(salary) AS 最低薪资,
    SUM(salary) AS 薪资总和
FROM employees;
```

## 5. 分组 GROUP BY / HAVING

```sql
-- 按部门分组统计
SELECT 
    dept_id,
    COUNT(*) AS 人数,
    AVG(salary) AS 平均薪资,
    MAX(salary) AS 最高薪资
FROM employees
GROUP BY dept_id;

-- 多列分组
SELECT 
    dept_id,
    gender,
    COUNT(*) AS 人数,
    AVG(salary) AS 平均薪资
FROM employees
GROUP BY dept_id, gender;

-- HAVING 过滤分组结果
SELECT 
    dept_id,
    COUNT(*) AS 人数,
    AVG(salary) AS 平均薪资
FROM employees
GROUP BY dept_id
HAVING COUNT(*) >= 2 AND AVG(salary) > 10000;
```

| | WHERE | HAVING |
|---|--------|--------|
| 时机 | 分组**前**，过滤原始行 | 分组**后**，过滤分组结果 |
| 聚合函数 | 不能用 | 可以用 |
| 典型用途 | `salary > 8000` | `AVG(salary) > 8000` |

## 6. 分页 LIMIT

```sql
SELECT * FROM employees LIMIT 10;           -- 前 10 条
SELECT * FROM employees LIMIT 10 OFFSET 20; -- 跳过 20 条，取 10 条
SELECT * FROM employees LIMIT 20, 10;       -- 等价写法：偏移 20，取 10
```

分页公式（页码从 1 开始，每页 `size` 条）：

```sql
-- 第 page 页：LIMIT (page - 1) * size, size
-- 例：第 3 页，每页 10 条 → LIMIT 20, 10
SELECT * FROM employees ORDER BY id LIMIT 20, 10;
```

> 深分页（`OFFSET` 很大）会扫过大量行再丢弃，大数据量场景需换「基于上次最大 id」等方案，此处不展开。

## 7. JOIN 连接查询

```sql
-- 内连接：只返回两表都匹配的行
SELECT e.name, d.dept_name
FROM employees e
INNER JOIN departments d ON e.dept_id = d.id;

-- 左连接：保留左表全部行，右表无匹配则填 NULL
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id;

-- 右连接：保留右表全部行
SELECT e.name, d.dept_name
FROM employees e
RIGHT JOIN departments d ON e.dept_id = d.id;

-- 自连接：同一张表别名两次（查员工及其上级）
SELECT 
    a.name AS 员工,
    b.name AS 上级
FROM employees a
LEFT JOIN employees b ON a.manager_id = b.id;

-- 多表连接（示例库仅两张业务表时可链式加条件）
SELECT e.name, d.dept_name, e.salary
FROM employees e
JOIN departments d ON e.dept_id = d.id
WHERE d.location = '北京';
```

### 全外连接（MySQL 不支持 FULL OUTER JOIN，用 UNION 模拟）

```sql
-- 左有右无 ∪ 右有左无（UNION 会去重）
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id
UNION
SELECT e.name, d.dept_name
FROM employees e
RIGHT JOIN departments d ON e.dept_id = d.id;
```

### ⚠️ ON vs WHERE（左/右连接易错）

```sql
-- ✅ 连接条件放 ON：无部门的员工仍会留下，dept_name 为 NULL
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id AND d.location = '北京';

-- ⚠️ 过滤条件放 WHERE：会把右表为 NULL 的行滤掉，效果接近内连接
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id
WHERE d.location = '北京';
```

## 8. 子查询

| 类型 | 含义 | 常见用法 |
|------|------|----------|
| 标量（单行单列） | 返回一个值 | `>` / `=` 等比较 |
| 列（多行单列） | 返回一列多值 | `IN` / `ANY` / `ALL` |
| 表（多行多列） | 当作临时表 | `FROM (子查询) t` |
| 相关子查询 | 外层每行驱动内层 | `EXISTS` |

```sql
-- 标量：薪资高于全公司平均
SELECT * FROM employees 
WHERE salary > (SELECT AVG(salary) FROM employees);

-- 列：部门在北京的员工
SELECT * FROM employees 
WHERE dept_id IN (SELECT id FROM departments WHERE location = '北京');

-- ANY / ALL
SELECT * FROM employees 
WHERE salary > ANY (SELECT salary FROM employees WHERE dept_id = 1);
-- > ANY：大于子查询中任意一个；> ALL：大于子查询全部

-- 相关 + EXISTS：有员工的部门
SELECT * FROM departments d
WHERE EXISTS (
    SELECT 1 FROM employees e 
    WHERE e.dept_id = d.id
);

-- 表子查询：各部门平均薪资再过滤
SELECT * FROM (
    SELECT dept_id, AVG(salary) AS avg_sal
    FROM employees
    GROUP BY dept_id
) t
WHERE t.avg_sal > 10000;
```

## 9. UNION 合并结果

要求：各段 **列数相同**、对应列类型兼容；若要排序，**`ORDER BY` 只能写在最后一段**。

```sql
-- UNION：去重合并
SELECT name, salary FROM employees WHERE dept_id = 1
UNION
SELECT name, salary FROM employees WHERE dept_id = 2;

-- UNION ALL：不去重（通常更快）
SELECT name, salary FROM employees WHERE dept_id = 1
UNION ALL
SELECT name, salary FROM employees WHERE dept_id = 2
ORDER BY salary DESC;
```

## 10. 易错点速查

| 场景 | 注意 |
|------|------|
| `NULL` 比较 | 用 `IS NULL` / `IS NOT NULL`，不要用 `=` |
| `NOT IN` 子查询含 NULL | 可能导致整句无结果，优先 `NOT EXISTS` |
| 左连接 + `WHERE 右表列` | 易把外连接变成内连接，过滤尽量放 `ON` 或先确认意图 |
| `WHERE` 用别名 | 执行顺序在 `SELECT` 之前，不能用 `SELECT` 里的别名 |
| `SELECT *` | 笔记演示可以，接口/生产尽量写明确列名 |
| 深分页 | 大 `OFFSET` 性能差，见第 6 节 |
