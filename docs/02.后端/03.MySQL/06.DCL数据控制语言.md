# DCL 数据控制语言

DCL 用于权限控制，常用语句包括 `GRANT`、`REVOKE`。

<!-- more -->

```sql
-- 创建用户
CREATE USER 'zhangsan'@'localhost' IDENTIFIED BY 'password123';

-- 授权
GRANT SELECT, INSERT ON mydb.employees TO 'zhangsan'@'localhost';
GRANT ALL PRIVILEGES ON mydb.* TO 'zhangsan'@'localhost';

-- 撤销权限
REVOKE INSERT ON mydb.employees FROM 'zhangsan'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;

-- 删除用户
DROP USER 'zhangsan'@'localhost';
```
