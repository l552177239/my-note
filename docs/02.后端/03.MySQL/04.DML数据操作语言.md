# DML 数据操作语言

DML 用于操作表中的数据，常用语句包括 `INSERT`、`UPDATE`、`DELETE`。

<!-- more -->

## 1. INSERT 插入数据

```sql
-- 插入单条
INSERT INTO employees (name, gender, age, salary, dept_id, hire_date)
VALUES ('张三', 'M', 25, 8000.00, 1, '2024-01-15');

-- 插入多条
INSERT INTO employees (name, gender, age, salary, dept_id, hire_date)
VALUES 
    ('李四', 'F', 28, 12000.00, 2, '2023-06-01'),
    ('王五', 'M', 30, 15000.00, 1, '2022-03-20'),
    ('赵六', 'F', 22, 6000.00, 3, '2024-07-10');

-- 插入查询结果
INSERT INTO employees_backup
SELECT * FROM employees WHERE dept_id = 1;
```

## 2. UPDATE 更新数据

```sql
-- 更新单条
UPDATE employees 
SET salary = 9000.00 
WHERE id = 1;

-- 更新多条
UPDATE employees 
SET salary = salary * 1.1, 
    hire_date = '2024-01-01' 
WHERE dept_id = 2;

-- ⚠️ 危险：不加 WHERE 会更新全表！
UPDATE employees SET salary = 0;  -- 全部归零
```

## 3. DELETE 删除数据

```sql
-- 删除指定记录
DELETE FROM employees WHERE id = 1;

-- 删除满足条件的记录
DELETE FROM employees WHERE salary < 5000;

-- 清空表（逐行删除，保留自增ID）
DELETE FROM employees;

-- 与 TRUNCATE 的区别：
-- DELETE：DML，可回滚，逐行删除，保留自增计数器，触发器会执行
-- TRUNCATE：DDL，不可回滚，直接删除表再重建，重置自增计数器，不触发触发器
```
