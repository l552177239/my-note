# MySQL基础

本文快速过一遍 MySQL 常用基础操作，覆盖建库建表、增删改查与简单条件查询。

<!-- more -->

## 1. 库与表

```sql
CREATE DATABASE demo DEFAULT CHARACTER SET utf8mb4;
USE demo;

CREATE TABLE user (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(50) NOT NULL,
  age INT DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 2. 增删改查

```sql
-- 插入
INSERT INTO user (name, age) VALUES ('Alice', 20), ('Bob', 22);

-- 查询
SELECT id, name, age FROM user WHERE age >= 20 ORDER BY id DESC LIMIT 10;

-- 更新
UPDATE user SET age = 21 WHERE name = 'Alice';

-- 删除
DELETE FROM user WHERE id = 2;
```

## 3. 条件与聚合

```sql
SELECT age, COUNT(*) AS cnt
FROM user
WHERE name LIKE 'A%'
GROUP BY age
HAVING cnt >= 1;
```

常用运算符：`=`, `<>`, `>`, `<`, `IN`, `BETWEEN`, `LIKE`, `IS NULL`。

## 4. 索引与主键

```sql
-- 主键已在建表时声明
-- 普通索引
CREATE INDEX idx_user_name ON user(name);

-- 查看索引
SHOW INDEX FROM user;
```

主键唯一标识一行；索引加速查询，但会增加写入成本。

## 5. 表结构变更

```sql
ALTER TABLE user ADD COLUMN email VARCHAR(100) NULL;
ALTER TABLE user MODIFY COLUMN age INT NOT NULL DEFAULT 0;
DESC user;
```
