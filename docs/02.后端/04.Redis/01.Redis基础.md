# Redis基础

本文快速过一遍 Redis 常用数据类型与基础命令，便于日常缓存与简单数据结构操作。

<!-- more -->

## 1. 连接与键操作

```bash
redis-cli
PING                 # 返回 PONG
SET name Lious
GET name
EXISTS name
DEL name
EXPIRE name 60       # 60 秒后过期
TTL name
```

## 2. String

```bash
SET counter 1
INCR counter
GET counter
SETNX lock 1         # 不存在才设置，常用于简单锁
```

适合缓存对象序列化字符串、计数器、分布式锁等场景。

## 3. Hash / List / Set

```bash
# Hash：对象字段
HSET user:1 name Alice age 20
HGET user:1 name
HGETALL user:1

# List：队列/栈
LPUSH queue task1
RPOP queue

# Set：去重集合
SADD tags java python
SMEMBERS tags
SISMEMBER tags java
```

## 4. 过期与删除策略直觉

- 给热点 key 设置合理 TTL，避免缓存永不过期  
- 注意大 key、热 key；删除可用 `UNLINK`（异步）替代阻塞 `DEL`  
- 生产环境慎用 `KEYS *`，改用 `SCAN`

## 5. 简单使用场景

| 场景 | 类型/命令思路 |
| --- | --- |
| 页面缓存 | String + TTL |
| 用户会话 | Hash / String |
| 排行榜 | Sorted Set（`ZADD`/`ZRANGE`） |
| 消息队列 | List 或 Stream |

后续可继续补充 Sorted Set、发布订阅、持久化与集群等内容。
