# Java 操作 Redis（RedisTemplate）

基于 Spring Boot 使用 `RedisTemplate` 完成常用读写、删除与过期设置。

<!-- more -->

## 1. 依赖引入（Spring Boot）

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

---

## 2. 基础配置

`application.yml`：

```yaml
spring:
  redis:
    host: 127.0.0.1
    port: 6379
    password:
    database: 0
```

说明：

- `database`：Redis 逻辑库编号（默认 0）
- 生产务必配置密码、超时、连接池等（可按环境再细化）

---

## 3. 常用 API 示例

```java
@Autowired
private RedisTemplate<String, Object> redisTemplate;

// 存值（带过期）
redisTemplate.opsForValue().set("name", "redis学习", 10, TimeUnit.MINUTES);

// 取值
Object value = redisTemplate.opsForValue().get("name");

// 删除
redisTemplate.delete("name");

// 设置过期
redisTemplate.expire("name", 5, TimeUnit.MINUTES);
```

### 3.1 按数据类型对照

| Redis 类型 | RedisTemplate API |
|------------|-------------------|
| String | `opsForValue()` |
| Hash | `opsForHash()` |
| List | `opsForList()` |
| Set | `opsForSet()` |
| ZSet | `opsForZSet()` |

```java
// Hash
redisTemplate.opsForHash().put("user:1", "name", "Tom");
redisTemplate.opsForHash().get("user:1", "name");

// 自增（限流/计数常用）
Long count = redisTemplate.opsForValue().increment("counter", 1);

// 分布式锁雏形：SET NX EX
Boolean ok = redisTemplate.opsForValue()
        .setIfAbsent("lock:order:1", "1", 30, TimeUnit.SECONDS);
```

## 4. 实践建议

- Key 使用统一前缀与业务语义命名
- 写缓存尽量设置过期时间，避免永不淘汰的脏数据
- 注意序列化方式（JDK / JSON 等），团队内保持一致
