# Java 编程规范

对应 Python 文档中的「Pythonic」：写出符合 Java 社区惯例、可读且安全的代码。

## 1. 命名与格式

```java
package com.example.demo;     // 包：全小写

public class OrderService {   // 类：大驼峰
    public static final int MAX_SIZE = 100; // 常量：全大写

    private final OrderRepository repo;     // 字段：小驼峰

    public OrderDTO findById(long id) {     // 方法：小驼峰
        return repo.find(id);
    }
}
```

- 缩进 4 空格；大括号 K&R / Oracle 风格均可，团队统一
- 行宽建议 100～120
- 使用 IDE / `google-java-format` / Checkstyle 自动格式化

## 2. 惯用写法

```java
// 字符串内容比较
if ("ok".equals(status)) { }

// 空集合判断
if (list == null || list.isEmpty()) { }
if (list != null && !list.isEmpty()) { }

// 优先接口类型声明
List<String> names = new ArrayList<>();
Map<String, Integer> counter = new HashMap<>();

// try-with-resources
try (InputStream in = Files.newInputStream(path)) { }

// Optional：作为返回值表达「可能没有」，避免滥用为字段
Optional<User> user = findUser(id);
user.ifPresent(u -> System.out.println(u.getName()));

// switch 表达式（现代 Java）
String label = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "未知";
};
```

## 3. 该避免的写法

| 不推荐 | 推荐 |
|--------|------|
| `==` 比字符串内容 | `equals` / `Objects.equals` |
| 空 `catch` 吞异常 | 记录日志或向上抛 |
| 魔法数字散落 | 命名常量 |
| `new Thread` 无限制创建 | 线程池 |
| SQL 字符串拼接用户输入 | `PreparedStatement` |
| 过度继承 | 组合 + 接口 |

## 4. 注释与文档

```java
/**
 * 计算折扣后价格。
 *
 * @param price 原价，必须 &gt; 0
 * @param rate  折扣率，0~1
 */
public BigDecimal discount(BigDecimal price, BigDecimal rate) {
    // 实现...
}
```

- 注释解释「为什么」，而非复述代码
- 对外 API 写 Javadoc
