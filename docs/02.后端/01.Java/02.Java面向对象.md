# Java面向对象

本文梳理 Java 面向对象核心：封装、继承、多态，以及抽象类与接口。

<!-- more -->

## 1. 类与对象、封装

```java
public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {
        this.name = name;
        setAge(age);
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄不合法");
        }
        this.age = age;
    }

    public void intro() {
        System.out.println(name + " / " + age);
    }
}
```

字段用 `private` 隐藏，对外只暴露必要方法，这就是封装。

## 2. 继承

```java
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + " 在吃东西");
    }
}

public class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }

    public void bark() {
        System.out.println(name + "：汪汪");
    }

    @Override
    public void eat() {
        System.out.println(name + " 在啃骨头");
    }
}
```

- 子类用 `extends` 继承父类
- `super(...)` 调用父类构造
- `@Override` 表示重写父类方法

## 3. 多态

```java
public class PolyDemo {
    public static void main(String[] args) {
        Animal a1 = new Animal("动物");
        Animal a2 = new Dog("旺财");

        a1.eat(); // 动物 在吃东西
        a2.eat(); // 旺财 在啃骨头（运行时看实际类型）

        // 需要调用子类特有方法时再转型
        if (a2 instanceof Dog) {
            Dog dog = (Dog) a2;
            dog.bark();
        }
    }
}
```

父类引用指向子类对象，调用重写方法时执行子类实现。

## 4. 抽象类

```java
public abstract class Shape {
    public abstract double area();

    public void printArea() {
        System.out.println("面积 = " + area());
    }
}

public class Circle extends Shape {
    private double r;

    public Circle(double r) {
        this.r = r;
    }

    @Override
    public double area() {
        return Math.PI * r * r;
    }
}
```

抽象类不能实例化，可同时包含抽象方法和普通方法。

## 5. 接口

```java
public interface Flyable {
    void fly();
}

public interface Swimmable {
    void swim();
}

public class Duck implements Flyable, Swimmable {
    @Override
    public void fly() {
        System.out.println("鸭子飞起来了");
    }

    @Override
    public void swim() {
        System.out.println("鸭子游泳");
    }
}
```

- 类可实现多个接口
- Java 8+ 接口可有 `default` / `static` 方法

## 6. 常用补充

```java
// this：当前对象；super：父类
// final：类不可继承 / 方法不可重写 / 变量不可改
public final class Constants {
    public static final int MAX = 100;
}
```

| 概念 | 要点 |
| --- | --- |
| 封装 | 隐藏细节，控制访问 |
| 继承 | 复用父类，扩展子类 |
| 多态 | 同一调用，不同实现 |
| 抽象类 | 模板 + 部分实现 |
| 接口 | 约定能力，多实现 |

## 小结

- 先写好封装清晰的类
- 用继承复用共性，用接口描述能力
- 多态让代码面向抽象编程
