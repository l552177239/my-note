# Java异常处理

本文介绍 Java 异常体系、`try-catch-finally`、`throws` 与自定义异常的常见写法。

<!-- more -->

## 1. 异常体系

```
Throwable
├── Error          // 系统级错误，一般不捕获
└── Exception
    ├── RuntimeException   // 非检查异常（可不声明）
    └── 其他 Exception     // 检查异常（必须处理或声明）
```

常见运行时异常：`NullPointerException`、`IndexOutOfBoundsException`、`IllegalArgumentException`。

## 2. try / catch / finally

```java
public class TryCatchDemo {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("算术异常: " + e.getMessage());
        } finally {
            System.out.println("无论是否异常都会执行");
        }
    }
}
```

可捕获多个异常：

```java
try {
    // ...
} catch (NullPointerException | IllegalArgumentException e) {
    System.out.println(e.getMessage());
} catch (Exception e) {
    e.printStackTrace();
}
```

## 3. throws 与 throw

```java
public class ThrowsDemo {
    public static int parsePositive(String text) throws NumberFormatException {
        int n = Integer.parseInt(text);
        if (n <= 0) {
            throw new IllegalArgumentException("必须是正整数");
        }
        return n;
    }

    public static void main(String[] args) {
        try {
            System.out.println(parsePositive("12"));
            System.out.println(parsePositive("-1"));
        } catch (Exception e) {
            System.out.println("处理失败: " + e.getMessage());
        }
    }
}
```

- `throw`：主动抛出异常对象
- `throws`：方法声明可能抛出的异常

## 4. try-with-resources

自动关闭实现了 `AutoCloseable` 的资源：

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class TryWithResourceDemo {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("a.txt"))) {
            System.out.println(br.readLine());
        } catch (IOException e) {
            System.out.println("读文件失败: " + e.getMessage());
        }
    }
}
```

## 5. 自定义异常

```java
public class BizException extends RuntimeException {
    private final int code;

    public BizException(int code, String message) {
        super(message);
        this.code = code;
    }

    public int getCode() {
        return code;
    }
}

public class BizDemo {
    public static void login(String user, String pwd) {
        if (!"admin".equals(user) || !"123".equals(pwd)) {
            throw new BizException(401, "用户名或密码错误");
        }
    }

    public static void main(String[] args) {
        try {
            login("admin", "000");
        } catch (BizException e) {
            System.out.println(e.getCode() + ": " + e.getMessage());
        }
    }
}
```

## 6. 实践建议

| 建议 | 说明 |
| --- | --- |
| 不要吞异常 | `catch` 后至少记录日志 |
| 异常信息要具体 | 方便定位问题 |
| 业务失败用业务异常 | 与系统异常区分 |
| finally 慎写 return | 可能掩盖真实返回值/异常 |

## 小结

- 检查异常必须处理或声明，运行时异常按需捕获
- 优先 `try-with-resources` 管理资源
- 自定义异常表达业务语义
