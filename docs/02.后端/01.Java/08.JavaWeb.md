# JavaWeb

本文梳理 JavaWeb 基础：Servlet、请求响应、会话，以及过滤器与 MVC 分层思路。

<!-- more -->

## 1. 整体结构

```
浏览器 --HTTP--> Tomcat/Servlet容器
                    ├── Servlet（处理请求）
                    ├── Filter（前置/后置过滤）
                    └── JSP / 模板 / 前后端分离 JSON
```

现代项目多以后端提供 REST API，前端独立部署。

## 2. 最小 Servlet

```java
import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.io.PrintWriter;

@WebServlet("/hello")
public class HelloServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws ServletException, IOException {
        resp.setContentType("text/plain;charset=UTF-8");
        PrintWriter out = resp.getWriter();
        out.println("Hello, JavaWeb");
    }
}
```

访问：`http://localhost:8080/hello`

## 3. 获取请求参数并返回 JSON

```java
@WebServlet("/api/user")
public class UserServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String name = req.getParameter("name");
        if (name == null || name.isEmpty()) {
            name = "Guest";
        }

        resp.setContentType("application/json;charset=UTF-8");
        resp.getWriter().write("{\"name\":\"" + name + "\"}");
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        // 表单或 JSON 体解析后处理业务
        doGet(req, resp);
    }
}
```

实际项目解析 JSON 更常用 Jackson / Gson，而不是手写字符串。

## 4. Session 与 Cookie

```java
@WebServlet("/login")
public class LoginServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String user = req.getParameter("user");
        req.getSession().setAttribute("loginUser", user);
        resp.getWriter().write("login ok");
    }
}

@WebServlet("/me")
public class MeServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        Object user = req.getSession().getAttribute("loginUser");
        resp.getWriter().write(user == null ? "not login" : user.toString());
    }
}
```

- `Cookie`：保存在浏览器
- `Session`：保存在服务端，通过 SessionId 关联

## 5. Filter

```java
import javax.servlet.*;
import javax.servlet.annotation.WebFilter;
import java.io.IOException;

@WebFilter("/*")
public class LogFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        long start = System.currentTimeMillis();
        chain.doFilter(request, response);
        System.out.println("cost(ms) = " + (System.currentTimeMillis() - start));
    }
}
```

常用于登录校验、编码设置、跨域、日志等。

## 6. MVC 分层（常见演进）

```
Controller(Servlet/SpringMVC)
    -> Service（业务）
        -> DAO/Mapper（数据库）
```

| 层次 | 职责 |
| --- | --- |
| Controller | 接请求、参数校验、返回结果 |
| Service | 业务规则、事务 |
| DAO | SQL / 数据访问 |

当前主流会在 Servlet 之上使用 Spring Boot（Spring MVC + 自动配置）。

## 小结

- Servlet 是 JavaWeb 的核心抽象
- 先掌握请求、响应、Session、Filter
- 业务项目通常基于 Spring Boot 快速开发
