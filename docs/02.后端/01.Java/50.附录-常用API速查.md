### 一、输入输出

| API | 作用 | 示例 |
|-----|------|------|
| `System.out.println` | 换行输出 | `println("hi")` |
| `System.out.printf` | 格式化输出 | `printf("%d%n", 1)` |
| `Scanner` | 读键盘/流 | `new Scanner(System.in)` |
| `Files.readString` | 读文本文件 | `Files.readString(path)` |
| `Files.writeString` | 写文本文件 | `Files.writeString(path, s)` |

### 六、集合常用操作

```
Collection
├── List   → ArrayList / LinkedList
└── Set    → HashSet / LinkedHashSet / TreeSet
Map        → HashMap / LinkedHashMap / TreeMap
```

| 操作 | List | Set | Map |
|------|------|-----|-----|
| 添加 | `add(e)` | `add(e)` | `put(k,v)` |
| 判断 | `contains` | `contains` | `containsKey` |
| 删除 | `remove` | `remove` | `remove` |
| 大小 | `size` | `size` | `size` |
| 遍历 | for-each | for-each | `entrySet` |

```java
List<String> list = new ArrayList<>();
list.add("Java");
list.get(0);

Set<String> set = new HashSet<>();
set.add("a");

Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.getOrDefault("b", 0);
for (var e : map.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}
```

| 实现 | 特点 |
|------|------|
| `ArrayList` | 随机访问快 |
| `LinkedList` | 头尾插删快 |
| `HashSet` / `HashMap` | 无序，O(1) 均摊 |
| `TreeSet` / `TreeMap` | 有序（红黑树） |
| `LinkedHashMap` | 保持插入序 |

### 七、日期时间（java.time）

| 类型 | 用途 |
|------|------|
| `LocalDate` | 日期 |
| `LocalTime` | 时间 |
| `LocalDateTime` | 日期时间 |
| `ZonedDateTime` | 带时区 |
| `Instant` | 时间戳 |
| `DateTimeFormatter` | 格式化 |

```java
LocalDate today = LocalDate.now();
LocalDateTime dt = LocalDateTime.of(2026, 9, 16, 18, 0);
String s = dt.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm"));
```

> 新代码优先 `java.time`，少用 `Date` / `Calendar`。
