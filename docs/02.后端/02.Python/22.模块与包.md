# 模块与包

## 1. 模块导入

```python
# 导入整个模块
import math
print(math.sqrt(16))  # 4.0

# 导入模块中的特定函数/类
from math import sqrt, pi
print(sqrt(16))       # 4.0
print(pi)             # 3.14159...

# 使用别名
import numpy as np
from datetime import datetime as dt

# 导入所有（不推荐，污染命名空间）
from math import *

# 相对导入（在包内部使用）
from . import module_a      # 同级目录
from .. import module_b     # 上级目录
from .subpackage import c   # 子包
```

## 2. 创建模块

```python
# mymodule.py
"""这是一个示例模块"""

__version__ = "1.0.0"
__author__ = "Alice"

PI = 3.14159

def greet(name):
    """向用户问好"""
    return f"Hello, {name}!"

class Calculator:
    """简单计算器"""
    def add(self, a, b):
        return a + b

# 只在直接运行此文件时执行
if __name__ == "__main__":
    print("模块测试:")
    print(greet("World"))
    calc = Calculator()
    print(calc.add(2, 3))
```

## 3. 创建包

```
mypackage/
    __init__.py          # 包初始化文件
    module_a.py
    module_b.py
    subpackage/
        __init__.py
        module_c.py
```

```python
# __init__.py 内容
"""mypackage 包"""

__version__ = "1.0.0"

# 控制 from mypackage import * 导入的内容
__all__ = ["module_a", "module_b"]

# 自动导入常用内容
from .module_a import greet
from .module_b import Calculator
```

## 4. 模块搜索路径

```python
import sys

# 查看模块搜索路径
print(sys.path)

# 临时添加路径
sys.path.append("/path/to/my/modules")

# 通过环境变量 PYTHONPATH 永久添加
# export PYTHONPATH="/path/to/my/modules:$PYTHONPATH"

# 查看已加载模块
print(list(sys.modules.keys()))
```

## 5. 常用标准库模块

| 模块 | 用途 | 常用功能 |
|------|------|----------|
| `os` | 操作系统接口 | `os.path`, `os.environ`, `os.system()` |
| `sys` | 系统相关 | `sys.path`, `sys.argv`, `sys.exit()` |
| `pathlib` | 面向对象路径 | `Path`, 替代 `os.path` |
| `shutil` | 文件操作 | `copy()`, `move()`, `rmtree()` |
| `json` | JSON 处理 | `dump()`, `load()`, `dumps()`, `loads()` |
| `csv` | CSV 处理 | `reader()`, `writer()`, `DictReader()` |
| `re` | 正则表达式 | `match()`, `search()`, `findall()`, `sub()` |
| `datetime` | 日期时间 | `datetime`, `date`, `time`, `timedelta` |
| `time` | 时间相关 | `sleep()`, `time()`, `strftime()` |
| `random` | 随机数 | `randint()`, `choice()`, `shuffle()` |
| `math` / `statistics` | 数学/统计 | `sqrt()`, `mean()`, `median()` |
| `itertools` | 迭代器工具 | `permutations()`, `combinations()` |
| `functools` | 函数工具 | `lru_cache()`, `partial()`, `wraps()` |
| `collections` | 高级数据结构 | `Counter`, `defaultdict`, `deque`, `OrderedDict` |
| `typing` | 类型提示 | `List`, `Dict`, `Optional`, `Union` |
| `inspect` | 内省 | `getmembers()`, `signature()` |
| `logging` | 日志记录 | `basicConfig()`, `getLogger()` |
| `unittest` | 单元测试 | `TestCase`, `assertEqual()` |
| `argparse` | 命令行参数 | `ArgumentParser()` |
| `urllib` / `http` | 网络请求 | `request.urlopen()` |
| `sqlite3` | SQLite 数据库 | `connect()`, `execute()` |
| `hashlib` | 哈希算法 | `md5()`, `sha256()` |
| `base64` | Base64 编解码 | `b64encode()`, `b64decode()` |
| `copy` | 深拷贝/浅拷贝 | `copy()`, `deepcopy()` |
| `pickle` | 对象序列化 | `dump()`, `load()` |
| `threading` | 多线程 | `Thread()`, `Lock()` |
| `multiprocessing` | 多进程 | `Process()`, `Pool()` |
| `asyncio` | 异步IO | `async`, `await`, `run()` |
| `contextlib` | 上下文管理 | `contextmanager` 装饰器 |
| `dataclasses` | 数据类 | `@dataclass` 装饰器 |
| `enum` | 枚举 | `Enum`, `auto()` |
