# 附录：常用内置函数速查

<!-- more -->

### 一、输入输出

| 函数 | 作用 | 示例 | 返回值 |
|------|------|------|--------|
| `print()` | 输出到控制台 | `print("Hello", end="")` | `None` |
| `input()` | 获取用户输入 | `input("提示: ")` | `str` |
| `open()` | 打开文件 | `open("file.txt", "r")` | 文件对象 |

### 二、类型转换

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `int()` | 转整数 | `int("42")` → `42` | 可指定进制 `int("1010", 2)` |
| `float()` | 转浮点 | `float("3.14")` → `3.14` | `float("inf")` 无穷大 |
| `str()` | 转字符串 | `str(42)` → `"42"` | 任何对象都可转 |
| `bool()` | 转布尔 | `bool(0)` → `False` | 空值/0/空序列为 `False` |
| `list()` | 转列表 | `list("abc")` → `["a","b","c"]` | 可迭代对象转列表 |
| `tuple()` | 转元组 | `tuple([1,2])` → `(1,2)` | 可迭代对象转元组 |
| `set()` | 转集合 | `set([1,2,2])` → `{1,2}` | 自动去重 |
| `frozenset()` | 转不可变集合 | `frozenset([1,2])` | 可作为字典键 |
| `dict()` | 转字典 | `dict([("a",1)])` | 键值对序列转字典 |
| `bytes()` | 转字节 | `bytes("hello", "utf-8")` | 字符串编码为字节 |
| `bytearray()` | 转字节数组 | `bytearray(b"hello")` | 可修改的字节序列 |
| `chr()` | Unicode 码转字符 | `chr(65)` → `"A"` | 0-1,114,111 |
| `ord()` | 字符转 Unicode 码 | `ord("A")` → `65` | 与 `chr()` 互逆 |
| `hex()` | 转十六进制字符串 | `hex(255)` → `"0xff"` | |
| `oct()` | 转八进制字符串 | `oct(8)` → `"0o10"` | |
| `bin()` | 转二进制字符串 | `bin(5)` → `"0b101"` | |
| `complex()` | 转复数 | `complex(3, 4)` → `(3+4j)` | |

### 三、数学运算

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `abs()` | 绝对值 | `abs(-5)` → `5` | 复数返回模 |
| `max()` | 最大值 | `max(1, 5, 3)` → `5` | 可传 `key` 参数 |
| `min()` | 最小值 | `min([1, 5, 3])` → `1` | 可传 `key` 参数 |
| `sum()` | 求和 | `sum([1, 2, 3])` → `6` | 可指定 `start` |
| `pow()` | 幂运算 | `pow(2, 3)` → `8` | `pow(2, 3, 5)` 取模幂 |
| `round()` | 四舍五入 | `round(3.14159, 2)` → `3.14` | 银行家舍入法 |
| `divmod()` | 商和余数 | `divmod(17, 5)` → `(3, 2)` | 返回元组 |

### 四、序列操作

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `len()` | 获取长度 | `len("abc")` → `3` | 适用于字符串/列表/元组/字典/集合 |
| `range()` | 生成整数序列 | `range(5)` → `0,1,2,3,4` | 惰性求值 |
| `enumerate()` | 枚举索引和值 | `enumerate(["a","b"])` | 可指定 `start` |
| `zip()` | 并行合并序列 | `zip([1,2], ["a","b"])` | 以最短的为准 |
| `map()` | 映射转换 | `map(str, [1,2])` → `["1","2"]` | 返回迭代器 |
| `filter()` | 过滤元素 | `filter(lambda x: x>0, nums)` | 返回迭代器 |
| `sorted()` | 排序 | `sorted([3,1,2])` → `[1,2,3]` | 原序列不变，可传 `key`/`reverse` |
| `reversed()` | 反转 | `reversed([1,2,3])` | 返回迭代器 |
| `slice()` | 切片对象 | `slice(1, 5, 2)` | 用于 `__getitem__` |
| `all()` | 全为真 | `all([1, 2, 3])` → `True` | 空序列返回 `True` |
| `any()` | 任一真 | `any([0, 1, 0])` → `True` | 空序列返回 `False` |

### 五、对象 introspection（内省）

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `type()` | 查看类型 | `type(42)` → `<class int>` | |
| `isinstance()` | 类型判断 | `isinstance(5, int)` → `True` | 支持元组：`isinstance(x, (int, float))` |
| `issubclass()` | 子类判断 | `issubclass(bool, int)` → `True` | |
| `hasattr()` | 是否有属性 | `hasattr(obj, "name")` | |
| `getattr()` | 获取属性 | `getattr(obj, "name", "default")` | 可设默认值 |
| `setattr()` | 设置属性 | `setattr(obj, "name", "Alice")` | |
| `delattr()` | 删除属性 | `delattr(obj, "name")` | |
| `dir()` | 查看属性和方法 | `dir(str)` | 无参数查看当前作用域 |
| `vars()` | 查看 `__dict__` | `vars(obj)` | 无参数等价于 `locals()` |
| `id()` | 获取内存地址 | `id("hello")` | 判断是否为同一对象 |
| `hash()` | 获取哈希值 | `hash("hello")` | 用于字典键和集合元素 |
| `callable()` | 是否可调用 | `callable(print)` → `True` | |
| `repr()` | 开发字符串 | `repr("hello")` → `"'hello'"` | 用于调试 |
| `ascii()` | ASCII 表示 | `ascii("中")` → `"\u4e2d"` | 非 ASCII 转义 |
| `format()` | 格式化 | `format(3.14, ".2f")` → `"3.14"` | |
| `memoryview()` | 内存视图 | `memoryview(b"hello")` | 零拷贝访问二进制数据 |

### 六、类与对象

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `object()` | 创建空对象 | `object()` | 所有类的基类 |
| `super()` | 调用父类 | `super().__init__()` | MRO 顺序 |
| `classmethod()` | 类方法装饰器 | `@classmethod` | 第一个参数为 `cls` |
| `staticmethod()` | 静态方法装饰器 | `@staticmethod` | 无自动参数 |
| `property()` | 属性装饰器 | `@property` | 将方法变为属性 |
| `staticmethod()` | 静态方法 | `@staticmethod` | |
| `classmethod()` | 类方法 | `@classmethod` | |

### 七、迭代与生成

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `iter()` | 获取迭代器 | `iter([1,2,3])` | |
| `next()` | 获取下一个元素 | `next(iterator)` | 可设默认值防 `StopIteration` |
| `range()` | 整数序列 | `range(0, 10, 2)` | 可迭代，非列表 |
| `enumerate()` | 带索引枚举 | `enumerate(["a","b"], 1)` | |
| `zip()` | 并行迭代 | `zip(a, b)` | 可配合 `*` 解包 |
| `map()` | 映射 | `map(int, ["1","2"])` | 惰性求值 |
| `filter()` | 过滤 | `filter(None, [0,1,2])` | 保留真值 |
| `reversed()` | 反转 | `reversed([1,2,3])` | |

### 八、函数式编程

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `map()` | 映射 | `map(lambda x: x*2, [1,2])` | 返回迭代器 |
| `filter()` | 过滤 | `filter(lambda x: x>0, nums)` | 返回迭代器 |
| `reduce()` | 累积归约 | `reduce(lambda a,b: a+b, [1,2,3])` | `functools.reduce` |
| `zip()` | 并行合并 | `zip([1,2], ["a","b"])` | |
| `sorted()` | 排序 | `sorted([3,1,2], reverse=True)` | |

### 九、字符串相关

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `str()` | 转字符串 | `str(42)` | |
| `repr()` | 表示字符串 | `repr("hello")` | |

| `format()` | 格式化 | `format(3.14, ".2f")` | |

### 十、其他实用函数

| 函数 | 作用 | 示例 | 说明 |
|------|------|------|------|
| `help()` | 查看帮助 | `help(str.upper)` | 交互式文档 |
| `eval()` | 执行字符串表达式 | `eval("1 + 2")` → `3` | ⚠️ 安全风险 |
| `exec()` | 执行字符串代码 | `exec("x = 1 + 2")` | ⚠️ 安全风险 |
| `compile()` | 编译代码 | `compile("1+2", "", "eval")` | 配合 `eval`/`exec` |
| `globals()` | 全局命名空间 | `globals()` | 返回字典 |
| `locals()` | 局部命名空间 | `locals()` | 返回字典 |
| `breakpoint()` | 设置断点 | `breakpoint()` | Python 3.7+，调试用 |
| `__import__()` | 动态导入 | `__import__("os")` | 等价于 `import` |
| `open()` | 打开文件 | `open("file.txt", "r")` | |
