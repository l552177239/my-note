# 异常处理

## 1. 异常基础

异常是程序执行过程中出现的错误，Python 使用 `try-except` 结构捕获和处理异常。

```python
# 基础异常捕获
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")

# 捕获多种异常
try:
    num = int(input("请输入数字: "))
    result = 100 / num
except ValueError:
    print("输入的不是有效数字！")
except ZeroDivisionError:
    print("不能输入零！")

# 捕获所有异常（不推荐，会隐藏bug）
try:
    risky_operation()
except Exception as e:
    print(f"发生错误: {e}")
```

## 2. 异常处理结构

```python
# 完整结构：try - except - else - finally
try:
    file = open("data.txt", "r")
    data = file.read()
except FileNotFoundError:
    print("文件不存在！")
    data = ""
except PermissionError:
    print("没有权限读取文件！")
    data = ""
else:
    print(f"成功读取 {len(data)} 个字符")
finally:
    if 'file' in locals() and not file.closed:
        file.close()
    print("文件操作结束")
```

## 3. 常用内置异常

| 异常类型 | 触发场景 | 示例 |
|----------|----------|------|
| `SyntaxError` | 语法错误 | 漏写冒号、括号不匹配 |
| `NameError` | 使用未定义的变量 | `print(x)`（x未定义） |
| `TypeError` | 类型不匹配 | `"2" + 2` |
| `ValueError` | 值不合适 | `int("abc")` |
| `IndexError` | 索引越界 | `lst[10]`（列表只有3个元素） |
| `KeyError` | 字典键不存在 | `d["不存在的键"]` |
| `AttributeError` | 对象没有该属性 | `"hello".append("x")` |
| `ZeroDivisionError` | 除以零 | `10 / 0` |
| `FileNotFoundError` | 文件不存在 | `open("不存在的文件.txt")` |
| `IOError` / `OSError` | IO操作失败 | 磁盘满、权限不足 |
| `ImportError` | 导入失败 | `import 不存在的模块` |
| `ModuleNotFoundError` | 模块找不到 | `import xxx`（Python 3.6+） |
| `RuntimeError` | 运行时错误 | 递归过深等 |
| `NotImplementedError` | 方法未实现 | 抽象方法被调用 |
| `StopIteration` | 迭代器耗尽 | `next()` 超出范围 |
| `AssertionError` | 断言失败 | `assert False` |
| `MemoryError` | 内存不足 | 创建超大对象 |
| `RecursionError` | 递归深度超限 | 无限递归（Python 3.5+） |

## 4. 自定义异常

```python
# 继承 Exception 创建自定义异常
class ValidationError(Exception):
    """数据验证错误"""
    def __init__(self, field, message):
        self.field = field
        self.message = message
        super().__init__(f"字段 '{field}': {message}")

class AgeError(ValidationError):
    """年龄验证错误"""
    def __init__(self, age):
        super().__init__("age", f"年龄 {age} 不在有效范围 0-150 内")

# 使用自定义异常
def validate_age(age):
    if not isinstance(age, int):
        raise ValidationError("age", "必须是整数")
    if age < 0 or age > 150:
        raise AgeError(age)
    return True

try:
    validate_age(200)
except AgeError as e:
    print(e)  # 字段 'age': 年龄 200 不在有效范围 0-150 内
```

## 5. 异常链与抛出

```python
# 主动抛出异常
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为零")
    return a / b

# 异常链：保留原始异常信息
try:
    result = int("abc")
except ValueError as e:
    raise RuntimeError("转换失败") from e

# 断言（用于调试，生产环境可用 -O 关闭）
def process_data(data):
    assert isinstance(data, list), "data 必须是列表"
    assert len(data) > 0, "data 不能为空"
    return sum(data) / len(data)
```
