# 变量与常量

<!-- more -->

### 1. 变量

变量是用于存储数据的容器。在 Python 中，**变量不需要声明类型**，直接赋值即可创建。

```python
# 变量赋值
name = "Alice"      # 字符串
age = 20            # 整数
height = 1.65       # 浮点数
is_student = True   # 布尔值

# 同时给多个变量赋值
a = b = c = 0       # a, b, c 都等于 0
x, y, z = 1, 2, 3   # 分别赋值

# 交换两个变量的值
a, b = b, a         # Pythonic 的交换方式
```

#### 变量命名规则

| 规则 | 说明 | 示例 |
|------|------|------|
| 只能包含字母、数字、下划线 | 不能有其他特殊字符 | `name1`, `_value` ✅ |
| 不能以数字开头 | 首字符必须是字母或下划线 | `1name` ❌ |
| 区分大小写 | `Name` 和 `name` 是不同的变量 | |
| 不能使用关键字 | 如 `if`, `for`, `class` 等 | `class` ❌ |
| 建议用有意义的名称 | 提高代码可读性 | `student_name` ✅ |

#### 命名风格

```python
# 小写 + 下划线（推荐用于变量和函数）
student_name = "Alice"

# 大写 + 下划线（推荐用于常量）
MAX_SIZE = 100

# 驼峰命名（推荐用于类名）
class StudentInfo:
    pass
```

### 2. 常量

Python **没有真正的常量**，但约定用**全大写**命名表示常量，提醒不要修改。

```python
# 常量约定
PI = 3.14159
MAX_CONNECTIONS = 100
DEFAULT_TIMEOUT = 30

# 虽然可以修改，但不建议
PI = 3.14  # ⚠️ 不推荐！
```
