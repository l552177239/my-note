# Python基础

本文快速过一遍 Python 常用基础语法，配上可直接运行的示例。

<!-- more -->

## 1. 第一个程序

```python
print("Hello, Python!")
```

运行：`python hello.py`。Python 用缩进表示代码块，通常为 4 个空格。

## 2. 变量与数据类型

```python
# 基本类型
age = 20                 # int
price = 19.9             # float
name = "Lious"           # str
ok = True                # bool
nums = [1, 2, 3]         # list
person = {"name": name}  # dict
```

类型动态推断，可用 `type(x)` 查看。字符串可用 f-string：`f"hi, {name}"`。

## 3. 条件与循环

```python
score = 85
if score >= 90:
    level = "A"
elif score >= 60:
    level = "B"
else:
    level = "C"

for i in range(3):
    print(i)

n = 3
while n > 0:
    n -= 1
```

## 4. 函数与模块

```python
def add(a, b=0):
    """求和"""
    return a + b

print(add(1, 2))
```

用 `import math` / `from math import sqrt` 引入模块。入口判断：

```python
if __name__ == "__main__":
    print(add(1, 2))
```

## 5. 常用内置结构

```python
# 列表推导
squares = [x * x for x in range(5)]

# 字典取值
person = {"name": "Lious", "age": 20}
name = person.get("name", "unknown")

# 解包
a, b = (1, 2)
```

后续可继续补充面向对象、异常处理、虚拟环境与包管理等内容。
