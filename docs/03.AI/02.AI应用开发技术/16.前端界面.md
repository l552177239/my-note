# 16. 前端界面

> 系列第 16 篇。前 15 篇都在后端——curl 和 Swagger 能看到结果，但非技术用户用不了。这一篇用 **React + TypeScript + Vite** 搭一个聊天界面，接 FastAPI 的 **SSE 流式输出**，让用户看到回答一个字一个字地出现。

## 1. 学习目标

## 2. 为什么要流式输出

非流式（前 15 篇的做法）：

```
用户点发送 → 等 5~15 秒（界面一片空白）→ 整段回答一次性出现
```

流式：

```
用户点发送 → 0.5 秒后第一个字出现 → 逐字显示 → 完成
```

**用户体感差异巨大**：一个是"卡死了"，一个是"在思考"。LLM 生成本来就是一个 token 一个 token 出的，流式输出只是把它透传给用户。

## 3. 后端：SSE 接口

### 3.1 装依赖

```powershell
uv add sse-starlette
```

`sse-starlette` 封装了 SSE 的心跳、断线检测、连接清理，比手写 StreamingResponse 稳。

### 3.2 新增 `app/routers/chat_stream.py`

```python
import json
import logging
from fastapi import APIRouter
from pydantic import BaseModel
from sse_starlette.sse import EventSourceResponse

from app.core.llm import client
from app.config import settings

logger = logging.getLogger(__name__)

router = APIRouter(prefix="/api/chat", tags=["chat-stream"])

class StreamRequest(BaseModel):
    message: str
    session_id: str | None = None

@router.post("/stream")
async def chat_stream(req: StreamRequest):
    async def event_generator():
        stream = await client.chat.completions.create(
            model=settings.ollama_model,
            messages=[{"role": "user", "content": req.message}],
            temperature=0.7,
            stream=True,   # 关键：让模型流式返回
        )
        try:
            async for chunk in stream:
                delta = chunk.choices[0].delta.content or ""
                if delta:
                    yield {
                        "event": "message",
                        "data": json.dumps({"delta": delta}, ensure_ascii=False),
                    }
            yield {"event": "done", "data": "[DONE]"}
        except Exception as e:
            logger.exception("Stream failed")
            yield {
                "event": "error",
                "data": json.dumps({"error": str(e)}, ensure_ascii=False),
            }

    return EventSourceResponse(event_generator())
```

### 3.4 配置 CORS

前端跑在 `localhost:5173`，后端跑在 `127.0.0.1:8000`——跨域。`main.py` 加：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],   # 前端地址
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

> 生产环境 `allow_origins` 要写具体域名，不要用 `["*"]`。

### 3.5 为什么用 SSE 而不是 WebSocket

| | SSE | WebSocket |
|---|---|---|
| 方向 | 单向（服务器 → 客户端） | 双向 |
| 协议 | 基于 HTTP | 独立协议 |
| 断线重连 | 浏览器自动 | 需自己实现 |
| 复杂度 | 低 | 中 |

聊天场景只需要"服务器往客户端推"，SSE 够用且更简单。

## 6. 前端：聊天组件

`src/components/ChatWindow.tsx`：

```tsx
import { useState, useRef, useEffect } from "react";
import type { Message } from "../types";

const API_URL = "http://127.0.0.1:8000/api/chat/stream";

export default function ChatWindow() {
  const [messages, setMessages] = useState<Message[]>([]);
  const [input, setInput] = useState("");
  const [streaming, setStreaming] = useState(false);
  const bottomRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    bottomRef.current?.scrollIntoView({ behavior: "smooth" });
  }, [messages]);

  async function sendMessage() {
    if (!input.trim() || streaming) return;
    const userMsg: Message = { role: "user", content: input };
    setMessages((prev) => [...prev, userMsg, { role: "assistant", content: "" }]);
    setInput("");
    setStreaming(true);

    try {
      const resp = await fetch(API_URL, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ message: input }),
      });
      if (!resp.body) throw new Error("No response body");

      const reader = resp.body.getReader();
      const decoder = new TextDecoder();
      let assistantContent = "";

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;
        const chunk = decoder.decode(value, { stream: true });
        // SSE 格式：event: message\ndata: {...}\n\n
        for (const line of chunk.split("\n")) {
          if (line.startsWith("data: ")) {
            const data = line.slice(6).trim();
            if (data === "[DONE]") break;
            try {
              const parsed = JSON.parse(data);
              if (parsed.delta) {
                assistantContent += parsed.delta;
                setMessages((prev) => {
                  const next = [...prev];
                  next[next.length - 1] = {
                    role: "assistant",
                    content: assistantContent,
                  };
                  return next;
                });
              }
            } catch {
              // 忽略解析错误（可能是心跳）
            }
          }
        }
      }
    } catch (e) {
      console.error("Stream failed", e);
      setMessages((prev) => {
        const next = [...prev];
        next[next.length - 1] = {
          role: "assistant",
          content: "抱歉，服务暂时不可用。",
        };
        return next;
      });
    } finally {
      setStreaming(false);
    }
  }

  return (
    <div style={{ display: "flex", flexDirection: "column", height: "100vh", maxWidth: 768, margin: "0 auto", padding: 16 }}>
      <div style={{ flex: 1, overflowY: "auto", marginBottom: 16 }}>
        {messages.map((m, i) => (
          <div
            key={i}
            style={{
              padding: 12,
              margin: "8px 0",
              borderRadius: 8,
              maxWidth: "80%",
              marginLeft: m.role === "user" ? "auto" : 0,
              background: m.role === "user" ? "#dbeafe" : "#f3f4f6",
            }}
          >
            {m.content || (streaming && i === messages.length - 1 ? "..." : "")}
          </div>
        ))}
        <div ref={bottomRef} />
      </div>
      <div style={{ display: "flex", gap: 8 }}>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && sendMessage()}
          placeholder="输入消息..."
          disabled={streaming}
          style={{ flex: 1, padding: "8px 12px", borderRadius: 8, border: "1px solid #ccc" }}
        />
        <button
          onClick={sendMessage}
          disabled={streaming || !input.trim()}
          style={{ padding: "8px 24px", borderRadius: 8, background: "#3b82f6", color: "white", border: "none", cursor: "pointer" }}
        >
          {streaming ? "生成中..." : "发送"}
        </button>
      </div>
    </div>
  );
}
```

> 上面用了内联 style 而不是 Tailwind，避免引入额外依赖。样式不是本篇重点，能看清消息、能输入就够了。

## 8. SSE 协议：三行说清

```
event: message
data: {"delta": "你"}

event: message
data: {"delta": "好"}

event: done
data: [DONE]
```

- **event**：事件类型，前端可以监听不同事件（message / done / error）
- **data**：数据体，JSON 字符串
- **空行**：事件分隔符

### 8.1 为什么不用浏览器原生 EventSource

浏览器原生的 `EventSource` 只支持 GET 请求，没法带 JSON body。聊天要传 `message`、`session_id` 等结构化数据，用 GET 拼 query 太丑。所以用 `fetch + ReadableStream` 手动解析 SSE 格式——这也是 LLM 流式聊天的常见做法。

## 10. 失败模式速查表

| 现象 | 原因 | 解法 |
|------|------|------|
| 前端报 CORS 错误 | 后端没配 CORS | main.py 加 CORSMiddleware，allow_origins 写前端地址 |
| 前端收到数据但界面不更新 | React 状态没触发重渲染 | `setMessages(prev => ...)` 必须返回新数组 |
| 流式中途断了 | Ollama 挂了或网络抖 | 后端 try/except 发 error 事件；前端显示"服务不可用" |
| 每个字都替换整条消息 | 每次 push 新消息而不是更新最后一条 | 用 `next[next.length - 1] = {...}` 更新最后一条 |
| SSE 连接立刻断开 | 反向代理或 uvicorn 超时 | 用 sse-starlette 自带心跳；生产在 nginx 配 `proxy_buffering off` |
| 中文乱码 | `json.dumps` 默认转义 | `ensure_ascii=False` |
| `[DONE]` 之后还有数据 | 后端没在 done 事件后结束 | event_generator 在 yield done 后自然结束 |
| 前端 fetch 报 Unexpected token | 后端返回的不是 SSE 格式 | 检查 EventSourceResponse；不要手动加 `\n\n` |
