## 题目

HashMap 的底层数据结构是什么？JDK 1.8 做了哪些优化？

## 答案

JDK 1.8 之前：数组 + 链表；JDK 1.8 起：数组 + 链表 + 红黑树。

主要优化点：

- 当链表长度 ≥ 8 且数组容量 ≥ 64 时，链表转为红黑树，降低最坏查询复杂度
- 扩容时优化了元素迁移与 hash 计算方式
- 引入 `Node` / `TreeNode`，头插改为尾插，降低并发下环形链表风险（仍不建议多线程共用 HashMap）

复杂度：平均 O(1)；退化或树化前冲突严重时接近 O(n)，树化后约 O(log n)。
