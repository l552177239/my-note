## 题目

JDK / JRE / JVM 分别是什么？关系如何？

## 答案

1. **JVM**：虚拟机，加载并执行 `.class` 字节码（解释 / JIT）；「一次编译，到处运行」靠各平台各自的 JVM。
2. **JRE**：运行环境 = JVM + 核心类库；只跑程序、不开发时理论上有 JRE 即可。
3. **JDK**：开发工具包 = JRE + 开发工具（`javac`、`jar`、`javadoc` 等）。
4. **关系**：JDK ⊃ JRE ⊃ JVM。

### 解释与扩展

- JVM 不关心源码，只认字节码；跨平台的关键是「同一份字节码 + 各平台 JVM」。
- JRE 提供运行所需的标准库（模块化后的 `java.base` 等）。
- JDK 在 JRE 之上增加编译、打包、调试与诊断工具，日常写代码必须装 JDK。

### 注意

- JDK 9 起模块化后，官方很少再单独发「独立 JRE」安装包；开发/部署多直接装 JDK。
- 生产跑应用本质仍是启动 JVM 执行字节码。
