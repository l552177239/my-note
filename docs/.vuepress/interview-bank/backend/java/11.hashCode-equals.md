## 题目

说一下 `equals` 和 `hashCode`

## 答案

1. `equals`：判两个对象是否「相等」；`Object` 默认比地址，子类常重写为比内容。
2. `hashCode`：返回对象的哈希值（`int`），供哈希表定位桶；`Object` 默认多与内存地址相关。
3. **契约**：`equals` 为 `true` → `hashCode` 必须相同；`hashCode` 相同 ≠ `equals` 一定为 `true`（允许碰撞）。
4. 重写了 `equals` 就必须同步重写 `hashCode`，否则 `HashMap` / `HashSet` 会丢元素或查不到。

### 解释与扩展

| | equals | hashCode |
|---|---|---|
| 作用 | 逻辑相等 | 哈希定位 |
| 默认 | `==`（同引用） | 与对象身份相关 |
| 相等时 | — | 必须相同 |
| 碰撞时 | 再调 `equals` 确认 | 可相同 |

哈希集合用法（如 `HashMap`）：

```text
put / get → hashCode 定桶 → 桶内再用 equals 比 key
```

```java
@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof User)) return false;
    User u = (User) o;
    return Objects.equals(id, u.id);
}

@Override
public int hashCode() {
    return Objects.hash(id); // 参与 equals 的字段都要参与
}
```

### 注意

- 参与 `equals` 的字段集合 = 参与 `hashCode` 的字段集合，否则违反契约。
- 放入哈希集合后不要改会参与 `equals`/`hashCode` 的字段（可变 key 会丢数据）。
- 可用 IDE / Lombok/`Objects.equals` + `Objects.hash` 生成，减少手写出错。
- `equals` 契约：自反、对称、传递、一致；对 `null` 返回 `false`。
