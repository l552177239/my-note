## 题目

什么是面向对象？谈谈你对面向对象的理解

## 答案

1. 面向对象是一种以「对象」为中心组织程序的编程范式：类是模板，对象是类的实例。
2. 核心特征通常概括为：封装、继承、多态，再加抽象。
3. 与面向过程（怎么做）、函数式（不可变与无副作用）、面向切面（横切关注点）等并列，侧重点不同。

### 解释与扩展

- **封装**：隐藏实现细节、保护数据，对外提供接口，降低耦合。实现上常用 `private` + getter/setter；注意封装层级不要过深。
- **继承**：复用父类能力并做扩展。Java 用 `extends`；单继承。
- **多态**：同一方法因对象类型不同而行为不同。重载属编译时多态，重写属运行时多态。
- **抽象**：提取共性、只声明能力。靠 `abstract` 类 / `interface` 实现。

### 注意

- 面试里可顺带对比其他范式，但主体应落在「对象 + 四大特征」。
- 多态、继承细节常会追问到重载/重写、抽象类/接口，可与后续题串联。
