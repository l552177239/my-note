## 题目

什么是字节码？采用字节码的好处是什么？

## 答案
 
1. **字节码**：
   - `javac` 编译 `.java` 源码得到 `.class` 文件中的中间指令；
   - 程序运行时，JVM 读取 `.class` 由解释器翻译为对应平台的机器码执行；
   - 运行过程中 JIT 会监测热点代码，将其编译优化为高性能机器码，提升运行效率；
2. **好处**：
   - **跨平台**：同一份字节码 + 各平台 JVM →「一次编译，到处运行」；
   - **安全**：加载前可做字节码校验，降低非法指令、越权访问风险；
   - **可优化**：运行时由解释器 / JIT 按热点再优化，兼顾启动与峰值性能；
   - **语言无关**：Kotlin、Scala 等也可编译到 JVM 字节码，共享生态。

### 解释与扩展

- JVM 只认字节码，不关心源码语言；跨平台的关键是「统一字节码格式 + 各 OS 上的 JVM 实现」。
- `.class` 里是操作码（opcode）+ 操作数的指令流，可用 `javap -c` 反汇编查看。
- 相对直接编译成原生机器码：换平台不必重编源码，只要有对应 JVM。

### 注意

- 字节码跨的是「装了 JVM 的平台」，不是无 JVM 也能跑。
- 性能最终仍依赖具体 JVM（解释 / C1 / C2、GC 等），字节码本身不等于已经最优的机器码。
