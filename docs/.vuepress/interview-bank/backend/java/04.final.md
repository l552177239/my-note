## 题目

简述 final 的作用？为什么局部内部类和匿名内部类只能访问局部 final 变量？

## 答案

1. `final` 表示「不可变」：
    - 修饰类 → 不可继承；
    - 修饰方法 → 不可重写；
    - 修饰变量 → 基本类型值不可变，引用类型引用不可变。
2. 局部 / 匿名内部类访问外层局部变量时，只能访问 `final` 或 effectively final 变量。
3. 原因：内部类编译后是独立 `.class`，会**拷贝**外层局部变量；要求不可变才能保证内外语义一致。

### 解释与扩展

- **修饰类**：如 `String`、`Integer`，防止被继承篡改语义。
- **修饰方法**：可被继承调用，但不能 Override。
- **修饰变量**：引用 `final` 只保证指向不变，对象内部字段仍可能被改。
- 局部 / 匿名内部类只能访问局部 `final` / effectively final 变量的原因：
  1. 编译期局部内部类生成独立 class 文件；
  2. 方法局部变量位于栈，方法结束就销毁；内部类对象在堆，可能晚于方法结束继续运行；
  3. 编译器把局部变量拷贝一份作为内部类的成员变量；
  4. 如果变量可以修改，栈上原值、堆中副本两份数据会不一致；
  5. 所以强制要求 `final` / effectively final，禁止重新赋值，保证副本与原始值一致。

### 注意

- Java 8 起不必显式写 `final`，只要实际未被重新赋值（effectively final）即可被内部类捕获。
