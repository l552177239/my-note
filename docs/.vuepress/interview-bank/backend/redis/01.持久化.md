## 题目

Redis 的 RDB 和 AOF 持久化有什么区别？如何选择？

## 答案

**RDB**：按策略生成内存快照（`BGSAVE`）。

- 优点：文件紧凑、恢复快、对性能影响相对可控
- 缺点：可能丢失最近一次快照后的数据

**AOF**：追加写命令日志。

- 优点：数据更安全（尤其 `everysec` / `always`）
- 缺点：文件更大；需 rewrite；相对 RDB 恢复可能更慢

**如何选择：**

- 可容忍分钟级丢失、偏重恢复速度 → RDB 或主打 RDB
- 更看重尽量少丢数据 → 开 AOF（常见 `appendfsync everysec`）
- 生产常见：**RDB + AOF 混合**（或开启 AOF 并保留 RDB 作备份），按业务 RPO/RTO 权衡
