## 题目

执行 `new Constructor(args)` 时引擎依次做了哪些事？构造函数 `return` 对象会怎样？

## 答案

1. **创建一个空对象**，作为将要返回的实例。
2. **链接原型**：该对象的 `[[Prototype]]` 指向构造函数的 `prototype`。
3. **绑定 `this`**：用该对象作为 `this` 执行构造函数（相当于 `apply`）。
4. **返回值规则**：若构造函数返回值是**对象类型**（且非 `null`），则返回该对象；否则返回刚创建的实例。

### 解释与扩展

简化实现：

```js
function _new(constructor, ...args) {
  var context = Object.create(constructor.prototype);
  var result = constructor.apply(context, args);
  return (typeof result === 'object' && result != null) ? result : context;
}
```

步骤口诀：**建对象 → 连原型 → 执行构造 → 返回对象则用返回值，否则用实例**。

### 注意

1. `return null` 仍走实例（`typeof null === 'object'` 但笔记实现用 `!= null` 排除）。
2. `return` 数字/字符串等原始值会被忽略，仍返回实例。
3. 箭头函数没有 `[[Construct]]`，不能 `new`。
