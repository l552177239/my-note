## 题目

什么是解构赋值？数组解构和对象解构有何不同？默认值何时生效？

## 答案

1. **定义**：按模式从数组或对象中取出值赋给变量。

```js
let [a, b, c] = [1, 2, 3];
```

2. **数组解构**：按**位置**取值；可用空位跳过；可嵌套。

3. **对象解构**：属性**无序**，变量名需与属性**同名**才能取到；改名写成 `foo: baz`。

```js
let { first: f, last: l } = { first: 'hello', last: 'world' };
let { title, children } = this.props; // 同名简写
```

函数参数也可解构：`({ name, age }) => {}`。

4. **默认值**：某位置**严格等于 `undefined`** 时才用默认值（内部用 `===`）。`null` 不会触发默认值。

5. **与 rest / 展开**：`...rest` 收剩余项（须放最后，且是真数组）；`...arr` 可展开数组合并。

### 解释与扩展

对象解构实质是 `let { foo: foo } = obj` 的简写。嵌套对象可 `let { foo: { bar } } = obj`。失败或不匹配时对应变量为 `undefined`（无默认值时）。

### 注意

1. 不能对 `undefined`/`null` 做对象解构，会 TypeError。
2. 数组空位不是 `undefined` 的「有值成员」，跳过写法是连续逗号。
3. rest 与 `arguments`：rest 是真数组；`arguments` 含全部参数且不是数组。
