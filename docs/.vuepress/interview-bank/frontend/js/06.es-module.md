## 题目

ES Module 如何命名导出、默认导出和导入？有哪些注意点？

## 答案

1. **命名导出**：`export { a, b, person }` 或声明时 `export const a = 1`。

2. **默认导出**：`export default App`（一个模块最多一个 default）。

3. **命名导入**：`import { a as c, b, person } from './app'`。`as` 改名后原名可在本模块另作他用。

4. **命名空间导入**：`import * as c from './app'`，`c` 上挂全部导出。

5. **副作用导入**：`import './app'`，执行模块顶层代码（相当于把该模块跑一遍）。

6. **静态性**：`import`/`export` 必须在模块**顶层**，不能放在块级/`if` 里，以便编译期静态分析。

### 解释与扩展

浏览器中需 `<script type="module">`。模块默认严格模式、有各自作用域、`this` 为 `undefined`。相对路径一般写 `./` 或 `../`。与 CommonJS（`require` 运行时加载、值拷贝）对比：ESM 是静态的、导出的是**绑定的实时映射**（live binding）。

### 注意

1. 默认导出导入：`import App from './app'`，不要写成 `{ App }`（除非它是命名导出）。
2. 带 `src` 的 script 若同时内嵌代码，行为以规范为准，习惯上外链脚本标签保持为空。
3. 循环依赖时 ESM 可能得到未初始化的绑定，需避免在顶层立刻用对方导出。
