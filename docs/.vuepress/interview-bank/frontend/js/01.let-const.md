## 题目

`let` / `const` 相对 `var` 有哪些关键差异？`const` 声明的对象为什么还能改属性？

## 答案

1. **块级作用域**：`let`/`const` 只在所在 `{}` 内有效；`var` 是函数作用域或全局。外层读不到内层 `let`；内层可声明同名变量。

2. **无变量提升（表现上）**：`var` 声明会提升，使用前是 `undefined`；`let`/`const` 提升到块顶但处于 **TDZ（暂时性死区）**，声明前访问会 `ReferenceError`。

3. **不可重复声明**：同一作用域不能用 `let`/`const` 重复声明（也不能与 `var` 重复同一名）。函数参数也不能在函数体顶层再用 `let` 声明同名。

4. **`const` 必须初始化**：只声明不赋值会 `SyntaxError`。绑定的**绑定本身**不能再赋值，再赋会 `TypeError`。

5. **`const` 对象可变属性**：`const` 保证的是**变量指向不能换**，对象/数组内部属性仍可改。

```js
const a = [];
a.push('Hello'); // 可以
a = ['Dave'];    // 报错
```

### 解释与扩展

ES6 声明变量方式还包括 `import`、`class`，加上 `var`/`function`/`let`/`const` 共六种。循环、`if` 里用 `let` 可避免 `var` 的循环闭包问题。

### 注意

1. 面试常问 TDZ：从进入块到 `let/const` 那一行之前都不能碰该变量。
2. 基本类型用 `const` 真只读；引用类型要冻结需 `Object.freeze`（浅冻结）。
3. 优先 `const`，需要重新赋值再用 `let`，少用 `var`。
