## 题目

`localStorage` 和 `sessionStorage` 有什么区别？常用 API 有哪些？相对 Cookie 的优势？

## 答案

1. **都是 Web Storage**：在客户端存字符串；**按源（协议+域名+端口）隔离**，站点只能读自己的数据。数据**不会**随每次 HTTP 请求自动带上。

2. **`localStorage`**：持久化，无过期时间（除非用户清缓存或代码删除）。容量约 **5MB** 量级（因浏览器而异），远大于 Cookie 的约 4KB。

3. **`sessionStorage`**：仅当前**标签页会话**有效，关标签即清。

4. **常用 API**：`setItem(k, v)`、`getItem(k)`、`removeItem(k)`、`clear()`、`key(i)`、`length`。也可用属性写法 `localStorage.a = '3'`。

5. **相对 Cookie**：Cookie 每次请求都带给服务器，不适合存大量数据；Storage 只在需要时用 JS 读写，减轻带宽、提升性能。

### 解释与扩展

只能存字符串，对象需 `JSON.stringify` / `parse`。同源的多个标签页共享 `localStorage`，可用 `storage` 事件监听其它文档的改动（本页自己的写入不会触发该事件）。

### 注意

1. 敏感信息（token）存在 Storage 有 XSS 风险，需权衡。
2. 隐私模式 / 用户禁用可能抛错，读写要 try-catch。
3. `sessionStorage` 刷新还在，新开标签是新会话。
