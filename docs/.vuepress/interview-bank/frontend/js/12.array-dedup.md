## 题目

数组如何去重？有哪些写法，性能大致如何？

## 答案

1. **`indexOf` + `filter`**：`arr.filter((item, i) => arr.indexOf(item) === i)`。实现简单，大数据量慢（约 O(n²)）。

2. **双层循环 + `splice`**：发现重复就删。要同步改 `length` 和下标。性能往往最差。

3. **`includes` 推入新数组**：`!result.includes(i) && result.push(i)`。同样偏慢。

4. **排序后相邻比较**（ES5 里相对快）：`sort` 后只跟前一项比，不同则推入。注意 `sort` 会改原数组，且对象/NaN 语义要单独考虑。

5. **`Set`**（简洁、快）：`Array.from(new Set(arr))` 或 `[...new Set(arr)]`。

6. **对象哈希**（笔记实测往往最快）：用对象键记录是否出现过，`for...of` 扫一遍。

```js
let result = [];
let obj = {};
for (let i of arr) {
  if (!obj[i]) {
    result.push(i);
    obj[i] = 1;
  }
}
```

### 解释与扩展

面试可先写 `Set`，再提哈希表一遍扫描、以及 `indexOf` 的平方复杂度。对象键会把数字转成字符串，`1` 和 `'1'` 会被当成同一个；需要区分类型时用 `Map`。

### 注意

1. `Set` 按 SameValueZero，可去重 `NaN`，但对象是引用相等。
2. 哈希法对 `obj[i]` 会走 toString，复杂类型会碰撞。
3. 排序法不稳定依赖元素可比较，对象数组不能这么去重。
