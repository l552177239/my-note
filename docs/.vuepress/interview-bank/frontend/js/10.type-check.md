## 题目

为什么 `typeof` 不够用？如何更准确地判断 JS 数据类型？

## 答案

1. **`typeof` 局限**：`typeof null === 'object'`；数组、普通对象、日期都是 `'object'`；无法区分 `Array` / `Date` / `RegExp` 等。

2. **更准确**：`Object.prototype.toString.call(value)`，返回 `[object Type]`。

| 值 | toString.call |
|---|---|
| 数字 | `[object Number]` |
| 字符串 | `[object String]` |
| 布尔 | `[object Boolean]` |
| undefined | `[object Undefined]` |
| null | `[object Null]` |
| 数组 | `[object Array]` |
| 函数 | `[object Function]` |
| Date | `[object Date]` |
| RegExp | `[object RegExp]` |
| 普通对象 | `[object Object]` |

3. **封装**

```js
function type(o) {
  var s = Object.prototype.toString.call(o);
  return s.match(/\[object (.*?)]/)[1].toLowerCase();
}
type([]);    // "array"
type(null);  // "null"
```

可再挂 `type.isArray` 等方法。

### 解释与扩展

还可用 `Array.isArray`、`value instanceof Ctor`（跨 iframe 可能失败）。`toString` 借原型方法，避免实例重写 `toString`。面试也可提 `Symbol.toStringTag` 会改变部分结果。

### 注意

1. 必须 `.call(o)`，直接 `o.toString()` 对数组会变成 join。
2. 包装对象 `new Number(1)` 的 typeof 是 object，toString 仍是 Number。
3. 不要用 `== null` 当类型判断，那只判断 null/undefined。
