## 题目

用 ES5 构造函数和 ES6 `class` 如何实现封装与继承？二者关系是什么？

## 答案

1. **ES5**：构造函数里定义实例属性（函数名习惯大写）；**方法挂在 `prototype`** 上以便共享。可用工厂函数包一层 `new`，参数更灵活。

```js
function Student(props) {
  this.name = props.name || '匿名';
  this.grade = props.grade || 1;
}
Student.prototype.hello = function () { /* ... */ };
```

2. **ES5 继承**：子构造里 `Parent.call(this, props)` 继承属性；原型用空函数中转避免共享实例状态，再修正 `constructor`。

```js
function inherits(Child, Parent) {
  var F = function () {};
  F.prototype = Parent.prototype;
  Child.prototype = new F();
  Child.prototype.constructor = Child;
}
```

3. **ES6**：`class` + `constructor` 定义属性；方法写在类体中（仍在原型上）。继承：`class Child extends Parent`，构造里必须 **`super(props)`** 再写子类字段。

```js
class PrimaryStudent extends Student {
  constructor(props) {
    super(props);
    this.age = props.age || 8;
  }
  getAge() { /* ... */ }
}
```

### 解释与扩展

`class` 是原型继承的语法糖，本质仍是构造函数 + prototype。ES6 写法更清晰，且 `extends` 会正确设置 `[[Prototype]]`，避免手写 `inherits` 出错。

### 注意

1. 子类构造里先 `super` 再访问 `this`，否则报错。
2. 类方法之间不要互相逗号分隔（不是对象字面量）。
3. `class` 声明不提升，且默认严格模式。
