## 题目

防抖和节流的区别是什么？如何用 `setTimeout`/`clearTimeout` 实现？各适用什么场景？

## 答案

1. **共同目的**：高频事件里减少函数执行次数，做性能优化。

2. **防抖 debounce**：每次触发都**重置计时**；只在**最后一次触发后再等待 wait 毫秒**才执行。连续触发则一直推迟。

```js
function debounce(func, wait) {
  let timeout = null;
  return function () {
    let context = this;
    let args = arguments;
    if (timeout) clearTimeout(timeout);
    timeout = setTimeout(() => {
      func.apply(context, args);
    }, wait);
  };
}
```

3. **节流 throttle**：一个时间窗口内**最多执行一次**。窗口内再触发直接忽略，到期才跑（下面是定时器版）。

```js
function throttle(func, wait) {
  let timeout = null;
  return function () {
    let context = this;
    let args = arguments;
    if (!timeout) {
      timeout = setTimeout(() => {
        timeout = null;
        func.apply(context, args);
      }, wait);
    }
  };
}
```

4. **场景对照**
   - **防抖**：搜索框输入完再请求；按钮防连点提交；窗口 `resize` 结束后再算布局；表单校验。
   - **节流**：滚动加载更多、拖拽 `mousemove`、射击间隔、监听 scroll 判断触底。

### 解释与扩展

口诀：**防抖等你停手；节流按节拍执行**。还可用时间戳实现「立即执行」的节流。闭包里保存 `this` 和 `arguments`，用 `apply` 保证回调里 this 正确。

### 注意

1. 搜索联想：输入过程用防抖减请求；若要输入时定期出建议也可用节流，题目里两者都可能被提到。
2. 滚动：节流控制频率；若只要「停滚后再算」则用防抖。
3. 组件卸载时要清 timer，避免泄漏。
