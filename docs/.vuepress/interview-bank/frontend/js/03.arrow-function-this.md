## 题目

箭头函数和普通函数的 `this` 有何不同？为什么常用于 `setTimeout` 回调？

## 答案

1. **箭头函数**：`this` 在**定义时**绑定为外层（词法）作用域的 `this`，**不是**调用时动态决定。之后不会因 `call`/`apply`/`bind` 改变箭头函数自身的 `this`（绑定发生在外层普通函数上才间接影响）。

2. **普通函数**：`this` 由**调用方式**决定。作为普通函数调用，非严格模式指向全局对象（浏览器 `window`），严格模式为 `undefined`。

3. **典型例子**

```js
function foo() {
  setTimeout(() => {
    console.log('id:', this.id);
  }, 100);
}
foo.call({ id: 42 }); // 输出 42
```

箭头函数定义在 `foo` 内，捕获的是 `foo` 被 `call` 后的 `this`（`{ id: 42 }`）。若回调写成普通 `function`，定时器里 `this` 通常是全局，会打出全局的 `id`（如 21）。

### 解释与扩展

语法：单参数可省 `()`；多语句用 `{}` 且需 `return`；返回对象字面量用 `({})` 包起来。箭头函数没有自己的 `arguments`、不能作构造函数（不能 `new`）、没有 `prototype`。

### 注意

1. 不要用箭头函数定义对象方法（若依赖 `obj.method()` 的 `this`）、也不要当 Vue 2 选项式 `methods`（会丢组件实例）。
2. 类字段里的箭头方法会绑定实例，和原型方法行为不同。
3. 口试金句：**「定义时的 this，而不是使用时的 this」**。
