## 题目

什么是 Ajax？如何用 `XMLHttpRequest` 发 GET/POST 并处理响应？

## 答案

1. **Ajax**：Asynchronous JavaScript and XML。用 JS 与服务器交换数据，**局部更新页面**，不必整页刷新。不是新语言，是用法。

2. **创建与发送**

```js
var xml = new XMLHttpRequest();
xml.open('GET', url, true); // method, url, async
xml.send();                 // POST 时 send(body)
```

- `open` 第三参 `true` 为异步（常用）。
- POST 若按表单/JSON 提交，需 `setRequestHeader`，再 `send` 字符串。

```js
xml.open('POST', url, true);
xml.setRequestHeader('Content-type', 'application/json');
xml.send(JSON.stringify(data));
```

3. **响应**：`responseText` 字符串；`responseXML` 为 XML。JSON 用 `JSON.parse(xml.responseText)`。

4. **`onreadystatechange`**：`readyState` 从 0 到 4。**4 且 `status === 200`** 表示成功可处理。

| readyState | 含义 |
|---|---|
| 0 | 未初始化 |
| 1 | 已 `open` |
| 2 | 已收到响应头 |
| 3 | 下载中 |
| 4 | 完成 |

### 解释与扩展

工作流程：JS 创建 XHR → 后台请求 → 回调里改 DOM。现代更多用 `fetch` / axios，但面试仍要求会手写 XHR。GET 适合简单查询；POST 适合提交较大或非 ASCII 数据。

### 注意

1. 应在 `send` 之前绑定 `onreadystatechange`（同步时顺序更敏感）。
2. 只判断 `readyState === 4` 不够，还要看 `status`（201 等也可视为成功，按接口约定）。
3. 跨域受同源策略限制，需 CORS。
