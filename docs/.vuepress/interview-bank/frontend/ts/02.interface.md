## 题目

TypeScript 中接口的作用是什么？如何定义可选属性、只读属性、索引签名？类如何 `implements` 接口？

## 答案

1. **接口**：为对象的「外形」命名，做结构性类型检查（鸭式辨型）。只要形状匹配即可，不必显式声明 implements（函数参数场景）。

2. **可选属性**：属性名后加 `?`，如 `color?: string`。可预定义可能存在的字段，并捕获拼写错误。

3. **只读属性**：`readonly x: number`，创建后不可再赋值。数组可用 `ReadonlyArray<T>`。变量用 `const`，对象属性用 `readonly`。

4. **索引签名**：`[index: number]: string` 或 `[propName: string]: any`，描述「用索引取值」的字典/数组形态；也可用来允许额外属性。

5. **implements**：类用 `implements` 强制符合接口契约，检查的是**实例公共部分**，不检查构造函数（静态部分）。

### 解释与扩展

- 对象字面量会做**额外属性检查**；拼错字段名会报错。绕过可用断言、索引签名，或先赋给中间变量（简单场景不建议绕过）。
- 接口还能描述**函数类型**（调用签名）、可索引类型；可继承多个接口。
- 数字索引的返回类型必须是字符串索引返回类型的子类型（因为 JS 会把数字索引转成字符串）。
- 混合类型：同一对象既可当函数调用，又带属性和方法（axios 实例就是典型）。

### 注意

- `implements` 只约束实例，构造器签名要单独用接口传给工厂函数（如 `new (h, m) => ClockInterface`）。
- 接口继承带 `private`/`protected` 的类时，只有该类的子类才能实现该接口。
