## 题目

什么是交叉类型？和联合类型有何不同？TypeScript 函数重载如何声明？还有哪些常用高级类型手段？

## 答案

1. **交叉类型**：`T & U` 把多个类型合并成一个，对象同时拥有各类型的成员。常见于 mixin：`extend<T, U>(first: T, second: U): T & U`。

2. **与联合对比**：联合是「或」（`string | number` 只能是其中之一）；交叉是「且」（`Person & Loggable` 既有 name 又能 log）。

3. **函数重载**：为同一函数提供多份类型签名，编译器按列表从上到下匹配。实现签名（如 `function pickCard(x): any`）**不算**重载列表的一部分。最精确的定义要写在最前面。

4. **其它**：字符串字面量类型、可空联合、`strictNullChecks` 下可选参数自动带 `| undefined`。

### 解释与扩展

- JS 函数常按参数类型返回不同结果（数组进则返回索引，数字进则返回牌对象）。重载把这种动态行为纳入类型系统。
- 交叉类型适合 JS 里不典型的 OOP（混入、插件对象）。
- 接口继承多个接口，效果上也是成员合成，和交叉类似但写在类型声明侧。

### 注意

- 重载匹配顺序很重要，宽泛签名放前面会挡住精确签名。
- 交叉后若属性同名且类型冲突，结果可能变成 `never`，使用前要理清字段。
- 面试常把交叉 / 联合 / 保护 / 重载放在一道「高级类型」里串讲。
