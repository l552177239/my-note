## 题目

如何用 CSS 实现单行、多行文本溢出省略号？如何用 JS 判断是否已经溢出？

## 答案

1. **单行省略**（三件套）

```css
overflow: hidden;
white-space: nowrap;
text-overflow: ellipsis;
```

容器需有确定宽度（或处于会限制宽度的布局中）。

2. **多行省略**（WebKit 方案，行数由 `-webkit-line-clamp` 决定）

```css
overflow: hidden;
white-space: normal;
text-overflow: ellipsis;
display: -webkit-box;
-webkit-line-clamp: 2;
-webkit-box-orient: vertical;
```

3. **JS 判断是否出现省略**：比较 **`scrollHeight` 与 `clientHeight`**，前者大于后者说明内容溢出。

```js
if (el.scrollHeight > el.clientHeight) {
  // 已溢出，可显示「展开」
}
```

### 解释与扩展

| 属性 | 含义 |
|---|---|
| scrollHeight | 内容总高度（含溢出不可见部分），不含边框、margin |
| clientHeight | 可视内容高度（含 padding），不含边框、水平滚动条 |
| offsetHeight | 含 padding + 边框的像素高度 |

标准方面，较新浏览器也支持 `line-clamp`，面试仍常写 `-webkit-line-clamp` 组合。

### 注意

1. 单行必须 `white-space: nowrap`，多行要改回 `normal`。
2. flex 子项上省略有时要加 `min-width: 0` 或 `overflow: hidden` 才生效。
3. 省略号出现后，纯 CSS 无法可靠「点击展开」，通常配合上述高度比较。
