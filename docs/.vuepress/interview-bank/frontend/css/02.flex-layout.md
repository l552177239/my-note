## 题目

什么是 Flex 布局？容器和项目分别有哪些常用属性？

## 答案

1. **定义**：Flex（Flexible Box）弹性布局。任意容器 `display: flex`，行内元素可用 `inline-flex`。子元素自动成为 **flex 项目**。设为 Flex 后，子项的 `float`、`clear`、`vertical-align` **失效**。

2. **两根轴**：默认主轴水平（main axis）、交叉轴垂直（cross axis）。项目默认沿主轴排列。

3. **容器属性（6 个）**
   - **`flex-direction`**：主轴方向。`row`（默认）/ `row-reverse` / `column` / `column-reverse`。
   - **`flex-wrap`**：换行。`nowrap`（默认，挤压缩）/ `wrap` / `wrap-reverse`。
   - **`flex-flow`**：以上二者简写，默认 `row nowrap`。
   - **`justify-content`**：主轴对齐。`flex-start` / `flex-end` / `center` / `space-between` / `space-around`。
   - **`align-items`**：交叉轴对齐。`stretch`（默认）/ `flex-start` / `flex-end` / `center` / `baseline`。
   - **`align-content`**：多根轴线对齐；**只有一行时无效**。

4. **项目属性（6 个）**
   - **`order`**：排序，越小越靠前，默认 0。
   - **`flex-grow`**：放大比例，默认 **0**（有剩余空间也不涨）。
   - **`flex-shrink`**：缩小比例，默认 **1**（空间不够会缩）；设 0 则不缩。
   - **`flex-basis`**：分配多余空间前的主轴尺寸，默认 `auto`。
   - **`flex`**：`grow shrink basis` 简写，默认 `0 1 auto`；常用 `auto`（`1 1 auto`）、`none`（`0 0 auto`）。**优先写 `flex` 简写**。
   - **`align-self`**：覆盖单个项目的 `align-items`。

### 解释与扩展

```css
.box { display: flex; justify-content: center; align-items: center; }
.item { flex: 1; } /* 等分剩余空间，且可收缩 */
```

`flex-grow` 全为 1 则平分剩余；某项为 2、其它为 1，则该项多分一倍剩余空间。

### 注意

1. WebKit 旧内核曾需 `-webkit-flex`。
2. `align-content` 与 `align-items` 不要混：前者管**多行轴线**，后者管**一行内交叉轴**。
3. `flex-shrink` 负值无效。
