## 题目

`transition` 和 `animation` 有什么区别？各自适合什么场景？

## 答案

1. **transition（过渡）**：在**属性值变化**时（如 `:hover`）从旧值平滑过渡到新值。需指定过渡的属性、时长，可选延迟和缓动（含 `cubic-bezier`）。

```css
.box { transition: all 0.3s; }
.box:hover { width: 150px; }
```

2. **animation（动画）**：用 **`@keyframes`** 定义多关键帧，元素可自动播放、循环、暂停，不依赖用户把样式改到「终态」。

```css
.rotate { animation: rotate 5s linear infinite; }
.rotate:hover { animation-play-state: paused; }
@keyframes rotate {
  0% { transform: rotate(0); }
  100% { transform: rotate(360deg); }
}
```

3. **对比**
   - 触发：transition 靠状态变化；animation 可自动跑。
   - 关键帧：transition 实质两端；animation 可中间多帧。
   - 循环：animation 有 `infinite`、`animation-play-state`；transition 一般一次。
   - 控制：animation 可设 delay、次数、方向（`alternate`）等。

### 解释与扩展

`transition: all .3s` 方便，但会过渡所有可动画属性，性能上更宜写具体属性（如 `transform`、`opacity`）。缓动除 `linear`/`ease` 外可用贝塞尔，X 轴 0~1，Y 可略超出做回弹。

### 注意

1. 并非所有属性都能高性能过渡，优先 **transform / opacity**。
2. 无限旋转、弹性进出用 animation；按钮 hover 变色变宽用 transition。
3. 旧浏览器可能需要 `-webkit-` 前缀。
