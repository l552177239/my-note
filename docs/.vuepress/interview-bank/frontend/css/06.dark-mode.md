## 题目

如何根据系统主题用 CSS 自动切换深色模式？JS 如何检测和监听？

## 答案

1. **思路**：在 `:root` 用 **CSS 变量**定义浅色主题色；用媒体查询 **`prefers-color-scheme: dark`** 覆盖为深色变量。组件只使用 `var(--bg)` 等，不必到处写两套选择器。

```css
:root {
  --bg: #fff;
  --textColor: #004050;
  --borderColor: rgba(0, 0, 0, 0.15);
}
@media (prefers-color-scheme: dark) {
  :root {
    --bg: rgb(30, 30, 34);
    --textColor: rgb(150, 150, 154);
    --borderColor: #2c2c3a;
  }
}
body {
  background: var(--bg);
  color: var(--textColor);
}
```

2. **`:root`**：匹配文档根（HTML 里即 `html`），选择器优先级高于普通 `html`。

3. **JS 检测**

```js
if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
  // 当前是深色
}
```

4. **监听系统切换**：`matchMedia(...).addListener`（新 API 为 `addEventListener('change', ...)`），分别监听 dark / light。

### 解释与扩展

`matchMedia` 返回 `MediaQueryList`，含 `matches`、`media`。仅跟系统偏好走时这样即可；若产品要「用户手动开关」，还需本地存储覆盖，不能只靠媒体查询。

### 注意

1. 桌面系统若不支持深色，可用手机系统深色模式验证。
2. 深浅两套对比度要够，别只改背景忘了边框/链接色。
3. `addListener` 已逐渐被 `addEventListener` 取代，新项目用后者。
