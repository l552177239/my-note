## 题目

如何实现元素的水平垂直居中？请给出几种面试常用方案及适用条件。

## 答案

1. **Flex（最常用）**：父级 `display: flex; justify-content: center; align-items: center;`。子项未知宽高也可。也可 `margin: auto` 配合 flex 子项。

2. **Grid**：父级 `display: grid; place-items: center;`（或 `place-content: center`）。

3. **绝对定位 + transform**：父 `position: relative`；子 `position: absolute; left: 50%; top: 50%; transform: translate(-50%, -50%);`。不依赖子元素固定宽高。

4. **绝对定位 + 负 margin**：子元素**宽高已知**时，`left/top: 50%` 再 `margin-left/top` 为宽高的一半负值。

5. **绝对定位 + 四向 0 + margin: auto**：子元素有明确宽高：`top/right/bottom/left: 0; margin: auto;`。

6. **行内/行内块 + 行高**：单行文本可用 `text-align: center` + `line-height` 等于容器高度（仅单行）。

7. **table-cell**：父 `display: table-cell; vertical-align: middle; text-align: center;`。

### 解释与扩展

| 方案 | 子宽高未知 | 备注 |
|---|---|---|
| Flex / Grid | 可以 | 现代首选 |
| transform | 可以 | 脱离文档流 |
| 负 margin | 需要已知 | 旧方案 |
| line-height | 单行文本 | 多行失效 |

水平单独居中：块级定宽可用 `margin: 0 auto`；行内用 `text-align: center`。

### 注意

1. 先确认是「块在块里」还是「文本在块里」，方案不同。
2. 绝对定位会脱离文档流，可能影响后续布局。
3. 面试优先讲 Flex，再补 1～2 种兜底。
