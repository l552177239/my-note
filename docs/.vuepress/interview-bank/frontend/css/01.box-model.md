## 题目

标准盒模型与 IE（替代）盒模型有什么区别？`box-sizing` 如何切换？为什么百分比宽度加像素 padding 会溢出？

## 答案

1. **组成**：元素由 **content、padding、border、margin** 组成盒模型。`margin` **不计入**元素自身 width/height，只占用外部空间。

2. **标准盒模型（`content-box`，默认）**：`width` / `height` **只等于内容区**。绘制到屏幕上的总宽 = 内容 + 左右 padding + 左右 border。

   例：`width:100px; padding:25px; border:5px` → 可见宽 = 100+25+25+5+5 = **160px**。

3. **IE / 替代盒模型（`border-box`）**：`width` / `height` 是**可见宽高**，已包含 padding 和 border。同样样式下总宽就是 **100px**，内容区被压缩。

4. **`box-sizing`**
   - `content-box`：`width` = 内容宽。
   - `border-box`：`width` = 内容 + padding + border。

5. **溢出场景**：自适应布局里宽度用 **百分比**（如 100%），padding/border 用 **px**。标准模型下 100% 已占满父宽，再加 px 内边距/边框就会超出父容器。设 `box-sizing: border-box` 后，百分比宽度包含 padding 和 border，总宽仍为 100%。

### 解释与扩展

```css
.box {
  box-sizing: border-box;
  width: 100%;
  padding: 16px;
  border: 1px solid #000;
}
```

工程上常对全局设 `*, *::before, *::after { box-sizing: border-box; }`，方便算宽。

### 注意

1. **margin 从不计入 width**，无论哪种盒模型。
2. 默认是标准模型，要 IE 行为必须显式 `border-box`。
3. 口试可记：content-box 加料会变胖；border-box 的 width 是「箱子外沿」。
