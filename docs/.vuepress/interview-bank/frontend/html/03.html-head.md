## 题目

`<head>` 里可以放哪些标签？分别说明 `title`、`style`、`link`、`script`、`noscript`、`base`、`meta` 的作用。

## 答案

1. **`<head>`**：存放文档元信息，不直接渲染正文。常见子元素：`title`、`style`、`meta`、`link`、`script`、`noscript`、`base`。

2. **`<title>`**：文档标题（规范上必需）。影响浏览器标签栏、收藏夹名称、搜索引擎结果标题。

3. **`<style>`**：内嵌 CSS。

4. **`<link>`**：声明文档与外部资源关系，最常见是外链样式表：`<link rel="stylesheet" href="...">`。

5. **`<script>`**：内嵌或通过 `src` 加载 JS。带 `src` 时元素应为空。
   - 无 `async`/`defer`：解析到该标签立刻下载并执行，**阻塞**后续解析。
   - **`async`**：异步下载，下载完尽快执行（顺序不保证，仅外部脚本）。
   - **`defer`**：异步下载，等文档解析完成再按顺序执行（仅外部脚本）。

6. **`<noscript>`**：浏览器不执行脚本时的替代文案。

7. **`<base>`**：为页面相对 URL 指定默认基地址，可设默认 `target`。

8. **`<meta>`**：元数据（编码、SEO、viewport 等），页面上不可见，由浏览器/爬虫读取。

### 解释与扩展

```html
<head>
  <meta charset="UTF-8">
  <title>Document</title>
  <link rel="stylesheet" href="mystyle.css">
  <script src="app.js" defer></script>
</head>
```

现代页面 JS 多用 `defer`，避免阻塞首屏；模块脚本 `<script type="module">` 默认延迟、按依赖顺序执行。

### 注意

1. `title` 对 SEO 和标签识别很重要，应简洁且能概括页面。
2. `base` 会影响所有相对路径，一处写错全站链接错乱。
3. `async` 脚本之间无执行顺序保证，不要依赖先后关系。
