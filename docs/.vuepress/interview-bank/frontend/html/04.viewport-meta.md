## 题目

移动端为什么要设置 viewport meta？常用属性有哪些？有什么注意点？

## 答案

1. **作用**：告诉移动浏览器如何控制**布局视口**（宽度、初始缩放等），避免页面按约 980px 桌面宽度渲染后再缩小，从而适配手机屏。

2. **常用写法**（响应式站点）

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

3. **content 常见指令**
   - **`width`**：视口宽度，常用 `device-width`，也可写像素（约 200~10000，旧默认约 980）。
   - **`height`**：视口高度（较少用）。
   - **`initial-scale`**：初始缩放（大于 0 到 10）。
   - **`minimum-scale` / `maximum-scale`**：允许缩放的最小/最大比例。
   - **`user-scalable`**：是否允许用户缩放（`yes` / `no`）。

### 解释与扩展

布局视口决定 CSS 布局所用宽度；视觉视口是用户当前看到的区域。`width=device-width` 让 CSS 像素宽度等于设备宽度，配合媒体查询做响应式。

无障碍上一般**不要禁用缩放**（`user-scalable=no` 或 `maximum-scale=1`），否则弱视用户无法放大。

### 注意

1. **非响应式站点不要乱加 `initial-scale=1`**：会按 100% 宽度渲染，用户只能左右拖或缩放才能看全。
2. 若同时 `initial-scale=1` 且禁止缩放，用户可能永远看不全内容。
3. 属性名是 **`minimum-scale`**，常见笔误 `minimun-scale` 无效。
