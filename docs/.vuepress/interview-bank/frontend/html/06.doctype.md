## 题目

`<!DOCTYPE>` 是什么？为什么要写？HTML5 和 HTML4 有何不同？

## 答案

1. **不是标签**：`<!DOCTYPE>` 是文档类型声明，必须放在文档**最前面**、`<html>` 之前。

2. **作用**：告知浏览器按哪种 HTML 规范解析，避免进入**怪异模式（quirks mode）**，从而按接近标准的方式渲染。

3. **HTML5**：不基于 SGML，**不需要引用 DTD**，写法极简：

```html
<!DOCTYPE html>
```

4. **HTML 4.01**：基于 SGML，声明需指向 DTD。例如 Strict（不含过时表现元素、不允许 frameset）：

```html
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">
```

还有 Transitional、Frameset，以及 XHTML 的对应 DTD。

### 解释与扩展

缺失或错误的 DOCTYPE 时，浏览器可能按旧 IE 怪异盒模型等行为排版，同一套 CSS 在不同浏览器差异放大。现代项目一律写 HTML5 的 `<!DOCTYPE html>` 即可，大小写不敏感但习惯大写 DOCTYPE。

### 注意

1. 声明前不要有 BOM、注释之外的输出，否则可能触发怪异模式。
2. 不要背一堆 HTML4 DTD，面试说清「触发标准模式 + HTML5 简写」即可。
3. 合法元素集合会随 Doctype 变化，旧文档需对照对应 DTD。
