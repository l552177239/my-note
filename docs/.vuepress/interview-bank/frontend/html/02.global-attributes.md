## 题目

什么是 HTML 全局属性？请列举常用全局属性及其作用。

## 答案

1. **全局属性**：几乎所有 HTML 元素都可使用的属性，写在开始标签上，形式为 `name="value"`，用来补充元素信息。

2. **常用全局属性**
   - **`id`**：文档内唯一标识，用于锚点、`getElementById`、样式选择器。
   - **`class`**：一个或多个类名，用于样式和批量选择。
   - **`style`**：行内 CSS。
   - **`title`**：额外说明，常见为鼠标悬停提示。
   - **`accesskey`**：快捷键（如 `Alt+字母`）。
   - **`tabindex`**：Tab 键切换顺序。
   - **`dir`**：文本方向（`ltr` / `rtl`）。

3. **书写规范**：属性名推荐小写；属性值加引号（一般双引号）；值本身含双引号时改用单引号。

### 解释与扩展

HTML5 还常见：`hidden`、`data-*` 自定义数据、`lang`、`contenteditable`、`draggable`、事件属性如 `onclick`。`id` 必须唯一，`class` 可复用。

### 注意

1. 不要用 `id` 当大量样式钩子，优先 `class`。
2. 行内 `style` 优先级高、难维护，生产更宜写在样式表。
3. `accesskey` 可能与系统/浏览器快捷键冲突，慎用。
