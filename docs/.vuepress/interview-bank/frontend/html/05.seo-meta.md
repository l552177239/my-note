## 题目

请介绍常用的 SEO 相关 meta（keywords、description、robots 等），以及使用时要注意什么。

## 答案

1. **`meta` 的角色**：提供机器可读的元数据，不显示在页面上；搜索引擎会读取部分字段辅助理解页面。

2. **`keywords`**：页面关键词短语。应能准确描述内容；过短引擎可能不认，也不宜过长（笔记中提到不宜超过约 874 字符）。现代主流搜索引擎对 keywords **权重很低甚至忽略**，不能当作核心 SEO 手段。

```html
<meta name="keywords" content="your tags" />
```

3. **`description`**：页面摘要，建议约 **150 字以内**、准确概括内容。可能出现在搜索结果摘要。

```html
<meta name="description" content="150 words" />
```

4. **`robots`**：控制爬虫是否索引本页、是否跟踪链接。常见值：`all`（默认可理解为索引+跟踪）、`none`、`index`/`noindex`、`follow`/`nofollow`。

```html
<meta name="robots" content="index,follow" />
```

5. **其它**：`author` 标注作者；`googlebot` 等针对特定爬虫。`http-equiv="refresh"` 可延时跳转，但容易被引擎视为误导而惩罚，SEO 场景慎用。

### 解释与扩展

| name | 作用 |
|---|---|
| keywords | 关键词（权重已很低） |
| description | 摘要，影响展示多于排名 |
| robots | 索引/跟踪策略 |
| author | 作者信息 |

真正影响 SEO 的还有：`title`、语义化结构、正文质量、`h1`、链接、性能与移动适配等。

### 注意

1. 每个页面 keywords / description 应**独特**，不要整站复制。
2. `noindex` 与 `nofollow` 含义不同，组合要按产品需求选。
3. 用 refresh 做跳转不如 301/302 HTTP 重定向规范。
