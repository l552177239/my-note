## 题目

请说明 HTML 块级元素与行内（内联）元素的区别，以及常见嵌套规则。

## 答案

1. **块级元素**：默认独占一行，宽度默认撑满父容器（除非指定 `width`），高度、行高、上下外边距均可控制。主要用于搭页面骨架、承载内容。常见：`div`、`h1~h6`、`p`、`ul`/`ol`/`li`、`table`、`form`、`hr` 等。

2. **行内元素**：默认与相邻元素同一行，宽高由内容决定，一般不能直接改宽高和上下 margin。主要用于修饰文本、控制细节。常见：`span`、`a`、`img`、`input`、`strong`、`em`、`br` 等。

3. **嵌套规则**
   - 块级可包含行内，以及**部分**块级；行内一般只能包含行内。
   - **`p`、`h1~h6`、`dt` 等**只能包含行内，不能再包块级（例如 `p` 里不能放 `div`）。
   - `li` 可以包含 `div`（二者都是内容容器）。
   - 块级与块级平级、行内与行内平级；不要用行内去包块级，例如 `<span><p></p></span>` 是错误嵌套。

### 解释与扩展

| | 块级 | 行内 |
|---|---|---|
| 换行 | 默认新行开始 | 同行排列 |
| 宽高 | 可设 | 默认由内容决定 |
| 典型用途 | 布局、区块 | 文本、控件 |

HTML5 更常用 **content model**（flow / phrasing）描述，但面试仍常按块级 / 行内口述。可用 CSS `display: block / inline / inline-block` 改变表现，语义标签本身不变。

### 注意

1. 浏览器会自动纠正非法嵌套（如 `p` 内的 `div` 会被提前闭合），DOM 结构可能和源码不一致。
2. `img`、`input` 虽是行内，但可用 CSS 设宽高；空元素如 `br`、`hr` 无内容。
3. 书写习惯：小写标签、成对闭合、空元素可写成 `<br />`。
