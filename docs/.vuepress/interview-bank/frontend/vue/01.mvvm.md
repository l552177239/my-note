## 题目

什么是 MVVM 模式？结合 Vue 说明数据如何驱动视图、视图如何回写数据。

## 答案

1. **MVVM**：M 是 Model（数据模型），V 是 View（视图），VM 是 ViewModel（视图模型）。

2. **数据 → 视图**：Model 通过 Data Bindings（响应式绑定）渲染到 View。

3. **视图 → 数据**：用户在页面上操作时，DOM listeners 监听变化，再更新 Model。

4. **Vue 中的对应**：`data` 等是 Model；模板/`el` 挂载的 DOM 是 View；Vue 实例（响应式系统 + 指令）扮演 VM，把两边同步起来。

### 解释与扩展

- 和 MVC 比，VM 承担了大量绑定与监听，业务代码较少直接操作 DOM。
- Vue 2 用 `Object.defineProperty` 做依赖收集（笔记语境为 Vue 2）；改数据会触发视图更新。
- 面试可补一句：单向数据流（props 下行）与双向绑定（`v-model`）是机制上的补充，不否定 MVVM。

### 注意

- 不要把 Vue 说成「只是模板引擎」；核心是 VM 对数据和视图的自动同步。
- 复杂跨组件状态仍可能用 Vuex，那是对 Model 层的集中，不是推翻 MVVM。
