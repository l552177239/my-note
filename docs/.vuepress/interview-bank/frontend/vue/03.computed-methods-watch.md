## 题目

计算属性、方法和侦听属性的区别是什么？三者都能实现同一功能时优先用哪个？watch 更适合什么场景？

## 答案

1. **computed**：基于响应式依赖**缓存**。依赖不变则多次访问不重新计算。适合由已有 data 派生展示值。

2. **methods**：每次触发重新渲染都会**再次执行**。适合点击等行为，或必须每次算的逻辑。

3. **watch**：观察某数据变化再执行回调。也有缓存，但写法通常比 computed 复杂。**适合异步操作或开销较大的操作**（请求、防抖后发事件）。

4. **选择**：同一功能三者都能做时，**优先 computed**。

### 解释与扩展

- computed 默认 getter，也可写 setter。模板里当属性用，不要当函数调用。
- watch 可 `immediate`、`deep`；Vue 2 里 `$watch` 可包一层 debounce 再 `$emit`。
- methods 里改 data 会再次渲染，注意不要在渲染路径里做重计算（应放到 computed）。

### 注意

- computed 不要有副作用（改别的状态、请求）；副作用放 watch / methods。
- 侦听对象要深比较时用 `deep: true`，性能更差。
- 「有缓存」不等于 watch 比 computed 更好；缓存 + 声明式派生才是 computed 的优势。
