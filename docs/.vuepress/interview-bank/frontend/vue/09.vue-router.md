## 题目

Vue Router 如何配置？`mode: 'history'` 和 hash 有何区别？路由懒加载怎么写、有什么好处？

## 答案

1. **基本用法**：`Vue.use(Router)`，`new Router({ routes })` 注入根实例。`<router-view>` 渲染匹配组件；`<router-link to="...">` 代替 `<a>` 做声明式跳转。

2. **history 模式**：`mode: 'history'`，URL 无 `#`，如 `/user/1`。依赖 HTML5 History API。hash 模式用 `#/path`，兼容好、不需服务端配合。

3. **动态路由**：`path: '/user/:id'`，组件内 `this.$route.params.id`。另有 `redirect`、`alias`（别名不改匹配到的路由记录）。

4. **懒加载**：`const Home = () => import('@/components/Home')`，替代顶部同步 `import`。打包出的 app.js 更小，进入对应路由再加载该 chunk。

### 解释与扩展

- history 需要服务端把所有前端路由 fallback 到 `index.html`，否则刷新 404。
- 懒加载本质是 webpack/rollup 的动态 import 分包。
- SPA 靠 URL 与 router 管理组件切换和状态，和 React Router 角色类似。

### 注意

- 开发用 history 时，webpack-dev-server 通常已配 historyApiFallback；生产 Nginx 要自己配。
- 路由组件同步引入会导致首包过大，列表页、详情页适合懒加载。
