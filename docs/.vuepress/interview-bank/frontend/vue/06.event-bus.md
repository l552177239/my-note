## 题目

非父子（含兄弟、跨层级）组件如何传值？EventBus 的原理和注意点是什么？

## 答案

1. **可选方案**：层层 props/$emit、**EventBus（发布订阅）**、Vuex。嵌套深时 Bus 或 Vuex 更省事。

2. **实现**：`Vue.prototype.bus = new Vue()`，所有实例共享同一个 Vue 实例当总线。发送：`this.bus.$emit('change', payload)`；接收：在 `mounted` 里 `this.bus.$on('change', handler)`。

3. **适用**：不限于兄弟，任意关系组件都可订阅同一事件名。本质是观察者模式。

### 解释与扩展

- 兄弟传值也可走父组件中转：子1 `$emit` → 父改 data → 子2 props。
- 大型应用优先 Vuex，Bus 适合轻量、临时解耦。
- 销毁时 `$off`，否则实例销毁后回调仍在，造成泄漏或报错。

### 注意

- 事件名要约定好，全局 Bus 容易命名冲突、难以追踪。
- Vue 3 移除了实例 `$on/$off`，官方不再推荐 EventBus；本题按 Vue 2 笔记回答。
- 箭头函数订阅时注意 `this` 指向；示例里用箭头函数保证改的是当前组件 data。
