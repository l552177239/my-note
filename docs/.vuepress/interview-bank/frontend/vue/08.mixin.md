## 题目

什么是混入（mixin）？和组件选项冲突时如何合并？实际项目里怎么用？

## 答案

1. **定义**：把组件可复用的选项（`data`、`created`、`methods` 等）抽到对象里，通过 `mixins: [myMixin]` 混入。多个组件共享同一段逻辑。

2. **合并策略**
   - **data**：递归合并，**冲突时组件数据优先**。
   - **钩子**：合并成数组，**都执行**；**混入钩子先于组件钩子**。
   - **methods / components / directives**：同名时**取组件的**。

3. **示例**：抽出 `playlistMixin`，组件必须实现 `handlePlaylist`；mixin 里放 computed、mounted、watch，组件覆盖同名方法做差异化。

### 解释与扩展

- 可通过 `this.$options` 查看合并后的选项。`Vue.extend` 用同一套合并策略。
- mixin 里故意 `throw` 可强制组件实现某方法（类似抽象方法）。
- Vue 3 更推荐 Composition API / composable 做复用，面试仍要会 mixin。

### 注意

- 来源不清晰、命名冲突、隐式依赖 `this`，是 mixin 的通病。
- 全局 `Vue.mixin` 影响每个组件，更难排查，慎用。
