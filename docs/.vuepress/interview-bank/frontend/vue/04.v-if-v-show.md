## 题目

`v-if` 和 `v-show` 的区别是什么？频繁切换时该用哪个？

## 答案

1. **v-if**：真正的条件渲染。条件为假时**不把元素渲染进 DOM**（销毁/重建，含内部组件生命周期）。

2. **v-show**：无论条件如何都会渲染到 DOM，只切换 CSS `display`。

3. **选择**：需要**非常频繁切换**用 `v-show`；运行时条件**很少改变**用 `v-if`。

### 解释与扩展

- `v-if` 可配 `v-else` / `v-else-if`；与 `v-for` 同节点时，Vue 2 中 `v-for` 优先级更高（官方不建议同用）。
- `v-show` 不能用在 `<template>` 上，也不支持 `v-else`。
- `v-if` 初始为假时有惰性：直到第一次为真才开始渲染，首次开销可能更高。

### 注意

- 权限控制、不该出现在 DOM 里的内容用 `v-if`，不要只用 `v-show` 藏起来。
- 带内部状态的组件用 `v-if` 切换会重置状态；要保状态用 `v-show` 或 `<keep-alive>`。
