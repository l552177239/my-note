## 题目

什么是插槽？默认插槽、具名插槽、作用域插槽分别怎么用？（按 Vue 2，可提到 2.6 的 `v-slot`）

## 答案

1. **插槽**：父组件写在子组件标签里的内容，由子组件模板中的 `<slot>` 出口渲染。slot 内可写**默认内容**，父未传入时才显示。

2. **具名插槽**：子 `<slot name="header">`；父侧旧语法 `slot="header"`，2.6+ 用 `<template v-slot:header>`（缩写 `#header`）。未具名的走默认插槽。

3. **作用域插槽**：数据由**子组件**提供（绑在 `<slot>` 上的 attribute，即插槽 prop），**父组件决定渲染什么**，并可二次处理数据。2.6 前 `slot-scope`，之后 `v-slot:default="slotProps"`。

### 解释与扩展

- `v-slot` 一般只能写在 `<template>` 上。
- 多个插槽时默认插槽名 `default` 不能乱省略。缩写 `#` 必须带插槽名，`#="{ user }"` 无效，应 `#default="{ user }"`。
- 典型场景：表格列自定义、列表项模板、布局的 header/footer。

### 注意

- 2.6 起 `slot` / `slot-scope` attribute 已废弃，新项目用 `v-slot`。
- 作用域插槽不是「父把数据传给子」，方向与 props 相反：子提供数据，父提供结构。
