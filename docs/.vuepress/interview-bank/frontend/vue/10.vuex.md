## 题目

什么是 Vuex？state、mutation、action 的职责是什么？为什么改 state 必须提交 mutation？

## 答案

1. **Vuex**：专为 Vue 的状态管理，类似 Redux。根实例注入 `store`，组件用 `this.$store.state`。

2. **state**：唯一状态树（可 modules 拆分）。读取建议放在 **computed** 里，保持响应式。

3. **mutation**：改变 state 的**唯一方法**。同步函数：`(state, payload) => { ... }`。组件 `this.$store.commit(type, payload)`，或 `mapMutations`。

4. **action**：不直接改 state，而是 **commit mutation**；可包含**任意异步**（请求、setTimeout）。`dispatch` 触发，可用 `mapActions`。类似 Redux Thunk。

### 解释与扩展

- 常用常量文件 `mutation-types.js` 避免魔法字符串。
- action 的 context 有 `commit` / `state` / `getters`；可解构 `({ commit })`。
- `dispatch` 可返回 Promise，便于组合多个异步 action（也可用 async/await）。
- mutation 必须同步，便于调试时时间旅行；异步副作用放 action。

### 注意

- 组件里直接 `this.$store.state.xx =` 能改但破坏规范，devtools 无法追踪。
- 不要在 mutation 里发请求。
- 模块化后注意 `namespaced`，commit/dispatch 可能要加模块前缀。
