## 题目

请按顺序说出 Vue 2 实例生命周期钩子，并说明 `beforeCreate` / `created` / `beforeMount` / `mounted` 时 `this.$el` 与 `data` 的状态。什么时候发请求比较合适？

## 答案

1. **创建**：`beforeCreate` → `created` → `beforeMount` → `mounted`。
2. **更新**：`beforeUpdate` → `updated`（data 变化后，虚拟 DOM 重新渲染并打补丁）。
3. **销毁**：`beforeDestroy` → `destroyed`（调用 `vm.$destroy()`）。

4. **$el / data 状态**
   - **beforeCreate**：`$el`、`$data`、`msg` 均为 `undefined`。
   - **created**：`$data` 与 `msg` 已初始化；**`$el` 仍是 `undefined`**（有 data，无 $el）。
   - **beforeMount**：已有 `$el`，内容仍是模板占位如 `{{msg}}`。
   - **mounted**：`$el` 已是渲染后的真实 DOM（如文案已替换）。

### 解释与扩展

- 钩子就是实例在某一时间点**自动执行**的函数。
- 父子挂载：`父 beforeCreate → 父 created → 父 beforeMount → 子完整挂载到 mounted → 父 mounted`。
- 接口请求：常在 **created**（已有 data，不依赖 DOM）或 **mounted**（需要操作 DOM / `$el` 时）。
- 定时器、全局事件在 `beforeDestroy` 里清掉，避免泄漏。

### 注意

- 不要在 `beforeCreate` 里用 `this.xxx` 访问 data。
- `updated` 里改 data 可能再次触发更新，小心死循环。
- 面试若追问 Vue 3：对应 `setup` / `onMounted` 等 Composition API，本题按 Vue 2 答即可。
