## 题目

Vue 2 中父组件如何给子组件传值、子组件如何通知父组件？为什么强调单向数据流？

## 答案

1. **父 → 子**：父用 `v-bind` 把数据绑到子组件标签上；子用 `props` 声明并接收。不用 `v-bind` 传入的是字符串，用 `v-bind` 传入的是表达式。

2. **子 → 父**：子 `this.$emit('fnX', value)` 派发自定义事件（可带多个值）；父 `@fnX="fnY"` 监听，在 `fnY` 里拿值。

3. **单向数据流**：prop 只能下行。父更新会流到子，子**不能直接改** prop，避免数据流混乱。

4. **改 prop 的正确方式**：当初始值用则拷到本地 `data`；当要转换则用 `computed`。要改父状态必须 `$emit` 让父改。

### 解释与扩展

- props 可以是数组，或对象（类型、默认值、校验）。模板 HTML 用 kebab-case，JS 里可用 camelCase。
- 组件标签上的 `v-on` 绑定的是**自定义事件**，不是原生 DOM 事件；子组件内部原生 click 再 `$emit` 才能触发父监听。需要原生可用 `.native`。
- 兄弟组件可「子1 emit → 父 data → 子2 props」，或 EventBus / Vuex。

### 注意

- 对象/数组作为 prop 时，子改内部字段父也会变（引用），仍视为反模式，应 emit。
- `v-model` 本质是 `:value` + `@input` 的语法糖。
