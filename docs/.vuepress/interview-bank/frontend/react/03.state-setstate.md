## 题目

class 组件中 state 是什么？`setState` 做什么？为什么 `onClick={this.handleClick.bind(this)}`？

## 答案

1. **state**：组件内部私有、完全受控的状态（类似 Vue 的 `data`）。在 `constructor` 里 `this.state = { num: 0 }`。state 变则重新 `render`。

2. **setState**：传入对象（或部分字段），触发更新并重新渲染。如点击 +1：`this.setState({ num: this.state.num + 1 })`；切换显隐：`this.setState({ show: !this.state.show })`。

3. **bind this**：class 方法默认不是自动绑定实例。作为事件回调抽出调用时 `this` 为 `undefined`。常用：`onClick={this.handleClick.bind(this)}`、构造函数里 `this.handleClick = this.handleClick.bind(this)`，或类字段箭头函数。

4. **更新特点**：多次 `setState` 对象形式会**合并（merge）**到当前 state，然后走更新流程触发 render（可能批处理）。

### 解释与扩展

- 构造函数要 `super(props)`，才能在 constructor 里用 props。
- 不要直接 `this.state.num++` 再期望视图更新，必须走 `setState`。
- 事件名 camelCase，传入函数而不是字符串：`onClick={handler}`。

### 注意

- `setState` 可能异步，紧接着读 `this.state` 不一定是新值；需要基于上一次结果时用函数式 `setState((s) => ...)`。
- `render` 里禁止 `setState`，否则死循环。
- 对象形式是**浅合并**，嵌套对象要自己展开。
