## 题目

什么是 props？父子组件如何传值？使用时有哪些注意点？

## 答案

1. **props**：父通过 JSX 属性传入的只读配置。函数组件用参数 `props`，class 用 `this.props`。缺省可用 `this.props.name || '点击'` 这类默认值。

2. **传值**：`<Welcome name="Sara" />` 或 `<Btn name="登录" color="hotpink" />`。数字、对象、函数用 `{ }`。所有属性组成一个 props 对象。

3. **两种组件等效**：`function Welcome(props) { return <h1>{props.name}</h1> }` 与 `class Welcome extends React.Component { render() { return <h1>{this.props.name}</h1> } }`。

4. **事件差异**：class 里常见 `onClick={() => this.props.onClick()}`；函数组件 `onClick={props.onClick}`（不要写成调用结果）。

### 解释与扩展

- 组件名必须大写，否则被当成原生标签。
- 可组合复用：同一 `Welcome` 传不同 `name`。
- props 单向流动，子不能改父的 props 对象来「通知」父，应回调函数（类似 Vue 的 $emit）。

### 注意

- props 应视为只读；要变的数据放 state。
- 把函数当 props 时注意 class 方法的 `this`（bind 或箭头函数）。
- 展开 `{...obj}` 会把多余字段也传下去，注意是否落到 DOM。
