## 题目

使用 Hook 必须遵守哪两条规则？React 如何把 state 和某次 `useState` 对应起来？条件逻辑应写在哪里？

## 答案

1. **只在最顶层调用**：不要在循环、条件、嵌套函数里调用 Hook，且放在任何 `return` 之前。保证每次渲染**调用顺序相同**。

2. **只在 React 函数中调用**：函数组件，或自定义 Hook。不要在普通 JS 函数里调。

3. **对应关系**：React **靠调用顺序**把 state 对上每一次 `useState` / `useEffect`。顺序乱了就会错位。

4. **条件 effect**：判断写在 Hook **内部**，而不是用 if 包住 `useEffect`。

### 解释与扩展

```jsx
useEffect(function persistForm() {
  if (name !== '') {
    localStorage.setItem('formData', name)
  }
})
```

- 用 `eslint-plugin-react-hooks`：`rules-of-hooks` 为 error，`exhaustive-deps` 为 warn。
- 自定义 Hook 也必须遵守同样规则，这样内部的 Hook 顺序仍然稳定。

### 注意

- 早期 return 写在 Hook 前面会破坏顺序，属于违规。
- 两条规则是面试高频；能讲清「顺序即身份」即可。
