## 题目

React Router 如何实现 SPA 路由？`BrowserRouter` 和 hash 有何不同？`Route`、`Link`、`Switch`、`withRouter` 怎么用？

## 答案

1. **定位**：官方路由库，通过管理 URL 切换组件和状态。Web 端常用 `react-router-dom`。

2. **基本结构**：最外层 `BrowserRouter`（笔记里常 `as Router`）。`Route` 的 `path` 匹配 URL，`component` 指定组件；`exact` 精确匹配。`Link to="/home"` 声明式跳转。

3. **history**：监听地址栏并把 URL 解析成对象。常见：`BrowserRouter`（History API，无 `#` 的正常路径）、hash（`#` 切换）、内存 history（服务端/测试）。放在顶层后，被匹配的组件 props 上有 `history`、`location`、`match`。

4. **其它**：`Switch` 只渲染第一个匹配的 Route/Redirect；不在路由树上的组件用 `withRouter` 注入路由 props。

### 解释与扩展

- `history.push` / `goBack` 做编程式导航；`match.params` 拿动态段。
- 条件渲染路由可用 `Route render={({ location }) => ...}`。
- 与 Vue Router 对比：都是 SPA 路由；React 用组件组合，Vue 用 `router-view` + 配置表。

### 注意

- BrowserRouter 生产环境同样需要服务端 fallback，否则刷新 404。
- v6 API 改为 `Routes`/`Route element={}`，面试按项目版本说；笔记是 v4/v5 风格（`component`、`Switch`）。
- `Link` 不要用成普通 `<a>` 否则整页刷新。
