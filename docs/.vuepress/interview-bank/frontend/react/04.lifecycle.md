## 题目

请说明 React class 组件首次挂载、更新、卸载的生命周期顺序。`componentDidMount` 和 `componentWillUnmount` 分别适合做什么？

## 答案

1. **首次挂载**：`constructor`（只一次，初始化 state）→ `componentWillMount` → `render`（必须，返回 JSX，不可改 state）→ `componentDidMount`（子组件已挂上，可用 refs）。

2. **更新**：`setState` 或 props 变化。`shouldComponentUpdate(nextProps, nextState)` 返回 bool 决定是否继续 → `componentWillUpdate` → `render` → `componentDidUpdate`。子组件在父 render 时还会走 `componentWillReceiveProps`。

3. **卸载**：`componentWillUnmount`。DidMount 里注册的定时器、订阅要在这里清掉。

4. **典型**：Clock 在 DidMount 里 `setInterval`，WillUnmount 里 `clearInterval`。挂载是第一次插入 DOM，卸载是从 DOM 删除。

### 解释与扩展

- 同一 DOM 节点上的 `<Clock />` 只创建一个 class 实例，所以能用 state 和生命周期。
- `shouldComponentUpdate` 返回 `false` 可跳过渲染（性能优化）。
- 首次走 WillMount/DidMount；之后对应 WillUpdate/DidUpdate。
- 新版应用更推荐 Hooks；面试 class 题仍要能画这条链。部分 Will* 已废弃（UNSAFE_），口述时点明即可。

### 注意

- `render` 必须纯，不能改 state、不能发请求。
- `componentWillReceiveProps` 父每次 render 子都会调，即使 props 没变。
- 卸载后还 `setState` 会告警，必须清副作用。
