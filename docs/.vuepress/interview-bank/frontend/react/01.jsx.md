## 题目

什么是 JSX？为什么 React 使用 JSX？它如何嵌入表达式、最终编译成什么？

## 答案

1. **定义**：用类似模板的语法描述 UI，是 JS 的**语法糖**，本质仍是 JS。编译后变成 `React.createElement(type, props, ...children)`，求值得到普通 JS 对象。

2. **为何使用**：把标记和逻辑放在同一个组件里，实现关注点分离；视觉上更直观。React 不强制 JSX，但实践中几乎都用。

3. **嵌入表达式**：`{ }` 内可放变量、运算、函数调用等任意 JS 表达式。属性：字符串用引号，变量用 `{user.avatarUrl}`。属性名 **camelCase**（如 `tabIndex`、`className`）。

4. **子元素**：标签可嵌套多个子节点；DOM 信息可归纳为标签名、属性、子元素三部分。

### 解释与扩展

```js
const element = <h1>Hello world</h1>
// 等价于
React.createElement('h1', null, 'Hello world')
```

- JSX 可作为值：赋值、传参、作为函数返回值。
- `ReactDOM.render(element, document.getElementById('root'))` 把它挂到真实 DOM。
- 需 Babel 转换；现代工具链默认已配。

### 注意

- 相邻 JSX 需要单一根（或 Fragment）。
- 小写标签当原生 DOM，**组件名必须大写**。
- 不要用引号包表达式：`src="{url}"` 是字符串而不是变量。
