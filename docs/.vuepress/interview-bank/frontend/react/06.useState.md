## 题目

`useState` 的参数和返回值是什么？为什么函数组件退出后 state 还能保留？和 class 的 setState 合并策略有何不同？

## 答案

1. **模式**：`const [count, setCount] = useState(0)`。参数是**初始 state**；返回当前值 + 更新函数。不必是对象，数字、字符串、数组都可以。

2. **为何叫 use 不叫 create**：state 只在首次渲染创建，之后返回当前值。函数执行结束局部变量会消失，**state 由 React 在重渲染间记住**。

3. **多个 state**：多次调用 `useState`，或一个 state 存对象。更新是**替换整个该 state 变量，不是浅合并**（与 class `this.setState` 不同）。

4. **限制**：Hook 在 class 内部不起作用；用来在函数组件里取代 class 的 state。

### 解释与扩展

- 点击：`setCount(count + 1)` 类似 `this.setState({ count: this.state.count + 1 })`。
- 相关数据可放同一对象；字段彼此独立则拆开，可读性更好。逻辑复杂可上 `useReducer`。
- 初始值若计算贵，可用惰性函数 `useState(() => ...)`（面试加分）。

### 注意

- 直接改 `count++` 或改对象内部不调用 setter，不会触发渲染。
- 对象 state 要更新时展开：`setUser({ ...user, name })`。
- Hook 调用顺序必须稳定（见 Hook 规则题）。
