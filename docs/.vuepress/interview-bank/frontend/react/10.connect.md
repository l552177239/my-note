## 题目

React 组件和 Redux store 默认没有关系，如何连接？`Provider` 和 `connect` / `mapStateToProps` 分别做什么？

## 答案

1. **react-redux**：官方绑定。核心接口 **Provider** 和 **connect**。

2. **Provider**：`<Provider store={store}>` 包住应用。只有被包住的子树里 `connect` 才能拿到 store（底层是 Context）。

3. **connect**：`connect(mapStateToProps, mapDispatchToProps)(Component)`。把 store 的一部分映射为当前组件 props。

4. **mapStateToProps**：`(state) => ({ comments: state.comments })`，映射后组件用 `this.props.comments`。store 数据很多，这里做选取。

### 解释与扩展

- 只有 connect 没有 Provider 会找不到 store。
- 发 action 可通过 `mapDispatchToProps` 或 `this.props.dispatch`，不必每个组件 import store。
- 现代写法多用 `useSelector` / `useDispatch`，原理仍是订阅 store + Context。

### 注意

- `mapStateToProps` 返回新对象会触发重渲染，选取粒度要合适。
- connect 柯里化两个括号；装饰器 `@connect` 曾出现过，不稳定，了解即可。
